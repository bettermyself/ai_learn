## 今日主题：字符串基本操作（反转、拼接）

## 知识点讲解

### 1. 字符串的内存特性
- Python 字符串是**不可变对象**
- 一旦创建，内容不能被修改
- 任何"修改"操作都是创建新字符串对象

### 2. 不可变性的原因
1. **哈希稳定性**：字符串常被用作字典 key 或哈希表键
2. **内部缓存优化**：小字符串驻留机制需要不可变性
3. **线程安全**：不可变对象在多线程环境下天然安全

### 3. 字符串反转的三种方法
| 方法 | 描述 | 时间 | 空间 |
|:---|:---|:---|:---|
| 切片 `s[::-1]` | Pythonic 写法 | O(n) | O(n) |
| 双指针 | 原地交换（需要列表） | O(n) | O(1) |
| `"".join(reversed(s))` | 内置函数 | O(n) | O(n) |

### 4. 切片语法
- `s[start:end:step]`
- `s[::-1]`：步长为 -1，从后往前取（反转）
- `s[::2]`：步长为 2，隔项取值

## 题目：LeetCode 344. 反转字符串

### 题目要求
- 输入：字符数组 `s`
- 要求：原地修改，O(1) 额外空间
- 不需要返回值

### 解法：双指针

```python
from typing import List

class Solution:
    def reverseString(self, s: List[str]) -> None:
        left, right = 0, len(s) - 1
        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1
```

### 关键点
1. `left` 从 0 开始，`right` 从末尾开始
2. 循环条件 `left < right`（奇数长度时中间元素无需自交换）
3. 并行赋值实现交换，无需 temp 变量

### 复杂度分析
- 时间复杂度：O(n/2) ≈ O(n)
- 空间复杂度：O(1)
