### 第一部分：CPU 缓存系统（Cache Hierarchy）

**核心概念**：
- 现代 CPU 速度远快于主内存，通过多级缓存弥补速度差距
- L1 Cache: ~32KB，~4 周期
- L2 Cache: ~256KB，~12 周期
- L3 Cache: ~12MB，~40+ 周期
- 主内存: ~100-200 周期

**L1/L2/L3 缓存区别**：
| 特性 | L1 Cache | L2 Cache | L3 Cache |
|:---|:---|:---|:---|
| **大小** | 32-64 KB | 256-512 KB | 4-64 MB |
| **延迟** | ~3-4 周期 | ~10-12 周期 | ~40-70 周期 |
| **位置** | 每个核心独立 | 每个核心独立 | 所有核心共享 |
| **结构** | 分为 L1d(数据) 和 L1i(指令) | 统一缓存 | 统一缓存 |

**缓存行（Cache Line）**：
- CPU 按 64 字节块读取，不是单字节
- 访问 `arr[0]` 时会加载周围 64 字节（约 16 个 int）
- 访问 `arr[1]` 时发生 Cache Hit，速度极快

### 第二部分：数组 vs 链表的缓存性能对比

**数组内存布局**：连续内存，缓存友好
```
[ arr[0] ][ arr[1] ][ arr[2] ] ... [ arr[15] ] ← 一个缓存行（64字节）
```

**链表内存布局**：分散内存，缓存不友好
```
[节点1]         [节点2]         [节点3]
 ↓ next         ↓ next         ↓ next
  ←────跳跃很远────→  ←────跳跃很远────→
```

**性能对比计算**（遍历 1,000,000 元素）：
- **数组**：~123 次 Cache Miss（L1 32KB 能装 8192 个 int）
- **链表**：~1,000,000 次 Cache Miss（几乎每次访问都未命中）

**结论**：数组比链表在遍历场景下可能快 10-100 倍
