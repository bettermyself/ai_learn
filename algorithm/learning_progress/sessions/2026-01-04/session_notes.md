## 讲解的核心算法模式与优化方法
1. **算法解法对比**:
   - **暴力解法**: O(n^2) 时间，O(1) 空间。
   - **哈希集合解法**: O(n) 时间，O(n) 空间（经典的空间换时间）。
   - **排序解法**: O(n log n) 时间，O(1) 空间（内存受限时的权衡之选）。

2. **哈希表底层原理 (Deep Dive)**:
   - **核心机制**: 哈希函数 (Hash Function) -> 取模映射 (Modulo) -> 直接寻址 (Direct Access)。
   - **Python 内部优化**:
     - **动态扩容**: 初始容量小（如8），负载高时按 2 的幂次方扩容。
     - **位运算优化**: 使用 `hash & (N-1)` 代替 `hash % N`（前提是 N 为 2 的幂），极大提升计算速度。
   - **哈希冲突**: 简要提及了冲突解决机制。

3. **其他快速查找数据结构**:
   - **collections.Counter**: 专门用于计数的哈希表，适合统计频率。
   - **collections.defaultdict**: 自动处理键不存在的情况。
   - **频率数组 (Frequency Array)**: 适用于数据范围小且密集的场景（如 0-100 的整数），比哈希表更快。
   - **布隆过滤器 (Bloom Filter)**: 空间极小，O(1) 查询，但存在误报（False Positive），用于海量数据去重。

## 学生完成的代码实现
- **排序解法**: 独立实现了基于排序的 Python 代码。
  ```python
  class Solution:
      def containsDuplicate(self, nums: List[int]) -> bool:
          nums.sort()
          for i in range(len(nums)-1):
              if nums[i] == nums[i+1]:
                  return True
          return False
  ```
  - 亮点: 正确处理了循环边界 `len(nums)-1` 防止越界，并准确分析了 O(n log n) 的时间复杂度。
