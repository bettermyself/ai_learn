## 讲解的核心算法模式与优化方法
1. **暴力解法 (Brute Force):**
   - 使用双重循环比较每个元素与其余所有元素。
   - 时间复杂度: O(n^2)
   - 空间复杂度: O(1)

2. **哈希集合优化解法 (Hash Set Optimization):**
   - 核心思想: "空间换时间"。
   - 遍历数组，使用哈希集合 (set) 存储已访问的元素。
   - 在每次迭代中，检查当前元素是否已存在于集合中 (O(1) 平均查找)。
   - 如果存在，则返回 `true`；否则，将元素添加到集合 (O(1) 平均插入)。
   - 时间复杂度: O(n)
   - 空间复杂度: O(n)

3. **数据结构选择的重要性:**
   - 重点解释了 `list` 的 `in` 操作是 O(n) 线性搜索。
   - 重点解释了 `set` 的 `in` 操作是基于哈希表的 O(1) 平均查找。
   - 强调了选择合适数据结构对算法性能的决定性影响。
