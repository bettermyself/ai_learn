## 核心知识点

### 频率统计模式

**标准框架**（两步走）:
1. 第一步：统计频率
2. 第二步：根据频率信息求解

**三种实现方式对比**:

| 方式 | 数据结构 | 时间复杂度 | 空间复杂度 | 适用场景 |
|:---|:---|:---|:---|:---|
| Counter | `collections.Counter` | O(n) | O(k) | 快速实现、面试推荐 |
| dict | 普通字典 | O(n) | O(k) | 需要自定义逻辑 |
| 数组 | 固定大小数组 | O(n) | O(1) | 字符集已知且较小 |

**应用场景**:
- 找唯一/不重复元素：出现次数为 1 的元素
- 找重复元素：出现次数 > 1 的元素
- Top K 高频元素：出现次数最多的 k 个元素
- 变位词检测：统计每个字符出现次数

## 知识点问答记录

### 问题1：字典的有序性

**学生提问**: Python 中字典的键是有序的吗？

**解答**:
- **Python 3.7+**: 字典是按插入顺序有序的（作为语言规范）
- **Python 3.6**: 有序但只是实现细节
- **Python 3.5 及之前**: 无序

**Counter 的有序性**: Counter 是 dict 的子类，继承有序行为。

---

### 问题2：为什么需要"再遍历原字符串"？

**学生回答**: ✅ 正确
- Python 3.6 或更早版本中字典的键是无序的
- 字典不存储索引信息，无法返回字符在原字符串中的位置

**补充理解**: 即使字典有序（Python 3.7+），推荐仍然遍历原字符串的原因：
1. 更直观、易理解
2. 兼容所有 Python 版本
3. 面试时更容易讲清楚思路
4. 复杂度仍然是 O(n)，没有额外开销

### 延伸学习：Top K 问题

**学生提问**: 如何对哈希表中值进行排序？

**解答**: 三种方法

#### 方法一：排序
```python
sorted_items = sorted(freq.items(), key=lambda x: x[1], reverse=True)
return [item[0] for item in sorted_items[:k]]
```
- 时间: O(n log n)
- 适用: k 接近 n 时

#### 方法二：堆
```python
import heapq
return heapq.nlargest(k, freq.keys(), key=freq.get)
```
- 时间: O(n log k)
- 适用: k 远小于 n 时

#### 方法三：快速选择（Quick Select）
- 时间: O(n) 平均
- 适用: 追求极致性能

## 性能深入探讨

### 数组 vs 哈希表：性能对比

**1. 索引计算**:
| 操作 | 数组 | 字典 |
|:---|:---|:---|
| 索引计算 | `ord(ch) - 97`，一次减法 | `hash(ch) % size` 或 `hash & mask` |
| 时钟周期 | ~1 | ~10-50+ |

**2. 内存布局**:
- **数组**: 连续内存，CPU 预读取友好（Cache Line 一次加载 64 字节）
- **字典**: 分散内存，可能 Cache Miss

**3. 实测差距**: 2-5 倍

**经验法则**: 能用数组就用数组（元素范围已知且小时）

## 题目学习：LeetCode 387

### 题目描述

给定一个字符串 `s`，找到它的第一个不重复的字符，并返回它的索引。如果不存在，则返回 `-1`。

**示例**:
- `s = "leetcode"` → 返回 `0`（`l` 是第一个唯一字符）
- `s = "loveleetcode"` → 返回 `2`（`v` 是第一个唯一字符）
- `s = "aabb"` → 返回 `-1`（没有唯一字符）

---

### 学生代码（字典版本）

```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        count_word_frequency = {}
        for ch in s:
            count_word_frequency[ch] = count_word_frequency.get(ch, 0) + 1
        for idx, ch in enumerate(s):
            if count_word_frequency[ch] == 1:
                return idx
        return -1
```

**评价**: ✅ 完全正确
- 正确实现频率统计两步走
- `get(ch, 0)` 处理新键
- `enumerate` 获取索引
- 正确处理无唯一字符的情况

---

### 优化版本（数组哈希）

```python
def firstUniqChar(s: str) -> int:
    freq = [0] * 26
    for ch in s:
        freq[ord(ch) - ord('a')] += 1

    for i, ch in enumerate(s):
        if freq[ord(ch) - ord('a')] == 1:
            return i
    return -1
```

**优势**:
- 空间复杂度从 O(k) 降为 O(1)
- 无哈希计算开销，更快
- CPU 缓存友好
