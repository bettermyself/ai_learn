# Day 4 复习笔记 - 2026年1月8日

## 复习主题：哈希表原理与字母异位词

## 复习内容

### 1. 哈希表容量为何是 2 的幂

**问题**：为什么哈希表容量通常设计为 2 的幂？

**答案**：
- 当 `size = 2^k` 时，`size - 1` 的二进制是 `k` 个 1（如 `0111`）
- `hash & (size-1)` 等价于 `hash % size`，都保留低 k 位
- 位运算只需 1 个时钟周期，取模需要 20-40 个时钟周期

### 2. 开放寻址法三态标记

**问题**：删除后为何不能标记为 EMPTY？三种状态的查找行为？

**答案**：
- 标记为 EMPTY 会中断后续冲突元素的查找
- 状态行为：
  | 状态 | 查找行为 |
  |:---|:---|
  | EMPTY | 停止，元素不存在 |
  | DELETED | 继续探测 |
  | OCCUPIED | 键匹配→返回值；不匹配→继续探测 |

### 3. 数组哈希索引映射

**问题**：`ord(ch) - ord('a')` 的作用？为何比 Counter 优？

**答案**：
- 将字母映射到索引 [0, 25]：'a'→0, 'b'→1, ..., 'z'→25
- 数组哈希底层是简单 int 列表，Counter 是完整哈希表
- 两者空间复杂度都是 O(1)，但数组哈希内存更小、访问更快

### 4. Counter 相等性比较

**问题**：含零计数的 Counter 比较结果？

**答案**：
- `Counter({'a': 1, 'b': 2}) == Counter({'a': 1, 'b': 2, 'c': 0})` → True
- Counter 重写 `__eq__`，忽略零计数和负数计数
