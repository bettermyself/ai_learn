### 2026年1月5日 - Day02: 数组内存模型理论
- **学习内容**：
  - LeetCode 1929: 数组串联 - 掌握 `nums * 2` 和 `nums + nums` 两种写法
  - LeetCode 1920: 基于排列构建数组 - 掌握列表推导式 `[nums[num] for num in nums]`
  - **核心理论**：
    - Python List 底层是动态数组，存储的是对象引用（指针）
    - 引用指针连续存储（8字节固定），对象本身可能分散在堆内存
    - 扩容策略：约 1.125 倍增长（`newsize + (newsize >> 3) + 常数`）
    - 与 C/C++ 区别：C++ 数组存储值本身，Python List 存储引用
    - 这使得 Python List 能容纳任意类型数据
- **掌握情况**：✅ 扎实，能清晰解释"引用 vs 值"的本质区别

### 2026年1月5日 - Day02 补充: 数组原地算法 (In-place Algorithm)
- **学习内容**:
  - LeetCode 1920 的 O(1) 空间解法
  - **核心技巧**:
    - 利用取模和整除在同一个内存单元存储两个数: `val = old + new * n`
    - 还原: `old = val % n`, `new = val // n`
  - **工程权衡**:
    - 优点: 空间复杂度降为 O(1)
    - 缺点: 需要两次遍历(编码+解码)，存在整型溢出风险(Integer Overflow)
  - **高阶视角**:
    - CPU 缓存亲和性: 理解 C 数组对比 Python List 在 Cache Miss 上的性能差异
    - 均摊复杂度: 理解为什么 O(N) 的扩容不影响 append 的 O(1) 总体评价
- **掌握情况**: ✅ 能够推导公式并分析优缺点，接触系统级性能视角

### 2026年1月7日 - Day04: 哈希表原理与字母异位词
- **核心理论**：
  - **哈希函数**：
    - 取模法 `hash % size`：简单但慢（除法 20-40 时钟周期）
    - 位运算法 `hash & (size-1)`：快速但要求 size 为 2 的幂
    - 当 size=2^k 时，两者等价（都保留低 k 位）
  - **哈希冲突**：
    - 链地址法：每个位置维护链表，冲突元素追加
    - 开放寻址法：寻找下一个空位（线性探测 +1、二次探测 +i²）
    - **查找机制**：不记住位置变更，查找时重新执行相同探测序列
    - **三态标记**：EMPTY（停止）、DELETED（继续）、OCCUPIED（检查）
  - **负载因子**：`元素数 / 容量`，超过 ~0.75 触发 2 倍扩容 + Rehash
  - **set vs dict**：set 只存键（去重、成员检查），dict 存键值对（结构化数据）
- **题目学习**：LeetCode 242 有效的字母异位词
  - **解法1 - Counter**：`return Counter(s) == Counter(t)` (O(n) Time, O(1) Space)
  - **解法2 - 数组哈希**：26位数组，`ord(ch)-ord('a')` 作为索引 (O(n) Time, O(1) Space) - 最优
  - **解法3 - 排序法**：`return sorted(s) == sorted(t)` (O(n log n) Time, O(n) Space)
- **掌握情况**：✅ 扎实，深入理解哈希函数位运算原理及开放寻址法查找机制

### 2026年1月7日 - Python 基础知识补充
- **学习内容**：
  - **Counter 相等性比较**：
    - Counter 是 dict 的子类，继承 `__eq__` 方法
    - `==` 比较键值对内容，忽略顺序和零/负数计数
    - Counter('aab') == Counter(['a', 'a', 'b']) → True
  - **Python 中 `==` vs `is`**：
    - `==`：判断值是否相等，调用 `__eq__()` 方法
    - `is`：判断内存地址是否一致，比较 `id()`
    - 自定义类不重写 `__eq__` 时，`==` 退化成 `is` 行为
  - **None 单例模式**：
    - None 是单例对象，内存中只有一个
    - 判断 None 应使用 `x is None`（PEP 8 推荐）
    - 优点：更快（直接比较地址）、更安全（避免 `__eq__` 重写影响）
- **掌握情况**：✅ 扎实，理解 Python 对象比较机制

### 2026年1月8日 - Day05: 哈希表实战 - 两数之和
- **核心理论 - 补数查找模式**：
  - 核心思想：把"查找两个数"的问题转化为"查找一个数的补数"的问题
  - 模式：对于当前元素 `nums[i]`，查找 `target - nums[i]` 是否之前出现过
  - 数据结构：字典存储 `值 → 下标` 映射，查询补数时直接获取下标
- **题目学习**：LeetCode 1 两数之和
  - **解法1 - 哈希法**：一遍遍历，先查询补数再插入当前值 (O(n) Time, O(n) Space) - 最优
  - **解法2 - 暴力法**：两重循环枚举所有组合 (O(n²) Time, O(1) Space)
  - **解法3 - 排序+双指针**：先排序后对撞指针，需保存原始索引 (O(n log n) Time, O(n) Space)
- **关键理解**：
  - **"先查询再插入"的重要性**：避免自我匹配（如 target=6 时两个3），避免覆盖有用的索引
  - **多答案场景**：若有多个答案或重复元素，可用 `值 → 索引列表` 存储，或用排序+双指针法
  - **值等价性**：相同值覆盖旧索引不影响结果正确性，因为值在求和中等价
- **掌握情况**：✅ 扎实，深入理解补数查找模式，能独立分析三种解法优劣及适用场景
