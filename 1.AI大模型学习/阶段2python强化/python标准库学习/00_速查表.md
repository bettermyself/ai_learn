## 2. shutil - 高级文件操作

### 主动回忆
```python

# Q3: 跨磁盘移动文件
shutil.___________(src, dst)  # 答案: move
```

### API 速查

| API | 说明 | 注意 |
|-----|------|------|
| `shutil.copy2(src, dst)` | 复制+保留元数据 | 比copy更完整 |
| `shutil.copy(src, dst)` | 仅复制内容 | 不保留元数据 |
| `shutil.move(src, dst)` | 移动/重命名 | 可跨文件系统 |
| `shutil.rmtree(path)` | 递归删除目录 | 危险操作! |
| `shutil.copytree(src, dst)` | 递归复制目录 | dst必须不存在 |
| `shutil.disk_usage(path)` | 磁盘使用情况 | 返回(总/已用/空闲) |

### 踩坑指南
| 陷阱 | 说明 |
|------|------|
| os.rename跨磁盘 | 只能在同文件系统内用 | 用shutil.move |
| rmtree无法恢复 | 删除后无法恢复 | 操作前先确认 |
| copytree目标存在 | 如果目标目录存在会报错 | 先删除或改用ditto |

### 记忆口诀
> **copy2保留全，move跨磁盘**
> **rmtree危险勿乱用，copytree目标要空缺**

| 符号 | 含义 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | 2024 |

| `%M` | 分钟 | 30 |
| `%S` | 秒 | 59 |

### timedelta 参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `days` | 天 | `timedelta(days=1)` |
| `hours` | 小时 | `timedelta(hours=2)` |
| `minutes` | 分钟 | `timedelta(minutes=30)` |
| `seconds` | 秒 | `timedelta(seconds=10)` |
| `weeks` | 周 | `timedelta(weeks=1)` |
| `.total_seconds()` | 总秒数 | `delta.total_seconds()` |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| **naive vs aware** | 无时区的时间无法比较 | 使用时区：`datetime.now(ZoneInfo(...))` |
| **strftime vs strptime** | 容易搞混 | **f=format(输出), p=parse(输入)** |
| **时间比较陷阱** | naive和aware不能直接比较 | 统一成aware再比较 |
| **时区导入** | Windows需要tzdata | `pip install tzdata` |
| **weekday返回值** | 0是周一，不是周日 | 0-6对应周一到周日 |

### 记忆口诀
> **strftime输出字符串，strptime解析字符串**
> **f=format格式化，p=parse解析**
> **timedelta时间加减，astimezone时区转**
> **naive无时区要避免，aware安全才靠谱**

| 陷阱 | 说明 | 解决 |
|------|------|------|
| **groupby必须先排序** | 只分组连续相同的值 | `groupby(sorted(data, key=...))` |

| **chain只拆一层** | 不会递归展开 | 嵌套列表需用 `chain.from_iterable` |

### 记忆口诀
> **chain链接序列，groupby分组先排序**
> **islice切迭代器，zip_longest补齐齐**
> **permutations有序排列，combinations无序组合**
> **product笛卡尔积，filterfalse反过滤**
