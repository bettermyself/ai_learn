### 踩坑指南
| 陷阱 | 说明 | 正确做法 |
|------|------|----------|
| 字符串路径混用 | `Path("dir") + "file"` ❌ | 用 `/` 拼接 |
| iterdir返回值 | 不是字符串，是Path对象 | 用 `f.name` 获取字符串 |
| read_text大文件 | 会全部加载到内存 | 大文件用 `with p.open()` |
| glob结果类型 | 返回生成器，不是列表 | 用 `list()` 转换或直接遍历 |

### 记忆口诀
> **Path对象除号拼，glob递归r开头**
> **读写text一行搞，stem取名suffix后**

## 2. shutil - 高级文件操作

### 主动回忆
```python
# Q1: 复制文件(保留元数据)
shutil.___________(src, dst)  # 答案: copy2

# Q2: 递归删除非空目录
shutil.___________(path)  # 答案: rmtree

# Q3: 跨磁盘移动文件
shutil.___________(src, dst)  # 答案: move
```

### API 速查

| API | 说明 | 注意 |
|-----|------|------|
| `shutil.copy2(src, dst)` | 复制+保留元数据 | 比copy更完整 |
| `shutil.copy(src, dst)` | 仅复制内容 | 不保留元数据 |
| `shutil.move(src, dst)` | 移动/重命名 | 可跨文件系统 |
| `shutil.rmtree(path)` | 递归删除目录 | 危险操作! |
| `shutil.copytree(src, dst)` | 递归复制目录 | dst必须不存在 |
| `shutil.disk_usage(path)` | 磁盘使用情况 | 返回(总/已用/空闲) |

### 踩坑指南
| 陷阱 | 说明 |
|------|------|
| os.rename跨磁盘 | 只能在同文件系统内用 | 用shutil.move |
| rmtree无法恢复 | 删除后无法恢复 | 操作前先确认 |
| copytree目标存在 | 如果目标目录存在会报错 | 先删除或改用ditto |

### 记忆口诀
> **copy2保留全，move跨磁盘**
> **rmtree危险勿乱用，copytree目标要空缺**


### API 速查

| API | 说明 | 示例 |
|-----|------|------|
| `json.dumps(obj)` | Python→JSON字符串 | `s = json.dumps({"a": 1})` |
| `json.loads(s)` | JSON字符串→Python | `obj = json.loads(s)` |

| 中文变\\u4e2d\\u6587 | ensure_ascii默认True | 设为False |
| loads先读再dump | 别搞混 | dumps/dump配对, loads/load配对 |

### 记忆口诀
> **s结尾是对字符串，无s直接写文件**
> **中文ASCII关掉，indent缩进美观点**

### 核心类速查

| 类 | 说明 | 导入 |
|----|------|------|

| `datetime.datetime` | 日期+时间 | `from datetime import datetime` |
| `datetime.timedelta` | 时间差/计算 | `from datetime import timedelta` |
| `datetime.timezone` | UTC时区 | `from datetime import timezone` |

### 常用API

| API | 说明 | 示例 |
|-----|------|------|
| `datetime.now()` | 当前本地时间 | `now = datetime.now()` |
| `datetime.now(tz)` | 当前时区时间 | `now = datetime.now(ZoneInfo("Asia/Shanghai"))` |
| `dt.strftime(fmt)` | 格式化输出 | `dt.strftime("%Y-%m-%d %H:%M")` |
| `datetime.strptime(s, fmt)` | 解析字符串 | `datetime.strptime("2024-01-01", "%Y-%m-%d")` |
| `dt.replace(**kw)` | 替换字段 | `dt.replace(year=2025)` |
| `dt.timestamp()` | 转时间戳 | `dt.timestamp()` |
| `datetime.fromtimestamp(ts)` | 时间戳转对象 | `datetime.fromtimestamp(1700000000)` |
| `dt.astimezone(tz)` | 时区转换 | `dt.astimezone(ZoneInfo("UTC"))` |
| `dt.weekday()` | 星期几(0-6) | 0=周一, 6=周日 |
| `dt1 - dt2` | 两个日期差 | 返回timedelta |
| `dt + timedelta` | 时间加减 | `dt + timedelta(days=1)` |

### 常用格式符号

| 符号 | 含义 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | 2024 |
| `%m` | 月份(01-12) | 01 |
| `%d` | 日期(01-31) | 15 |
| `%H` | 24小时制 | 14 |
| `%M` | 分钟 | 30 |
| `%S` | 秒 | 59 |
| `%A` | 星期名称 | Monday |
| `%a` | 星期缩写 | Mon |

### timedelta 参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `days` | 天 | `timedelta(days=1)` |
| `hours` | 小时 | `timedelta(hours=2)` |
| `minutes` | 分钟 | `timedelta(minutes=30)` |
| `seconds` | 秒 | `timedelta(seconds=10)` |
| `weeks` | 周 | `timedelta(weeks=1)` |
| `.total_seconds()` | 总秒数 | `delta.total_seconds()` |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| **naive vs aware** | 无时区的时间无法比较 | 使用时区：`datetime.now(ZoneInfo(...))` |
| **strftime vs strptime** | 容易搞混 | **f=format(输出), p=parse(输入)** |
| **时间比较陷阱** | naive和aware不能直接比较 | 统一成aware再比较 |
| **时区导入** | Windows需要tzdata | `pip install tzdata` |
| **weekday返回值** | 0是周一，不是周日 | 0-6对应周一到周日 |

### 记忆口诀
> **strftime输出字符串，strptime解析字符串**
> **f=format格式化，p=parse解析**
> **timedelta时间加减，astimezone时区转**
> **naive无时区要避免，aware安全才靠谱**

## 综合记忆卡片

### 模块关系图
```
文件操作: pathlib(路径) + shutil(复制删除) + os(系统接口)
数据序列化: json(配置) + csv(表格)
时间处理: datetime(日期) + zoneinfo(时区)
文本处理: re(正则) + string(常量)
随机生成: random(普通) + secrets(安全)
```

### 命名规律记忆
- **s结尾** = 操作字符串：`json.dumps()`, `json.loads()`, `strptime()`
- **无s** = 操作文件：`json.dump()`, `json.load()`, `strftime()`
- **递归** = r开头：`rglob()`, `rmtree()`
- **字典** = Dict开头：`DictReader`, `DictWriter`
