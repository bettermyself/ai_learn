### 踩坑指南
| 陷阱 | 说明 | 正确做法 |
|------|------|----------|
| 字符串路径混用 | `Path("dir") + "file"` ❌ | 用 `/` 拼接 |

| read_text大文件 | 会全部加载到内存 | 大文件用 `with p.open()` |
| glob结果类型 | 返回生成器，不是列表 | 用 `list()` 转换或直接遍历 |

### 记忆口诀
> **Path对象除号拼，glob递归r开头**
> **读写text一行搞，stem取名suffix后**

## 2. shutil - 高级文件操作

### 主动回忆
```python
# Q1: 复制文件(保留元数据)
shutil.___________(src, dst)  # 答案: copy2

# Q2: 递归删除非空目录
shutil.___________(path)  # 答案: rmtree

# Q3: 跨磁盘移动文件
shutil.___________(src, dst)  # 答案: move
```

### API 速查

| API | 说明 | 注意 |
|-----|------|------|
| `shutil.copy2(src, dst)` | 复制+保留元数据 | 比copy更完整 |
| `shutil.copy(src, dst)` | 仅复制内容 | 不保留元数据 |
| `shutil.move(src, dst)` | 移动/重命名 | 可跨文件系统 |
| `shutil.rmtree(path)` | 递归删除目录 | 危险操作! |
| `shutil.copytree(src, dst)` | 递归复制目录 | dst必须不存在 |
| `shutil.disk_usage(path)` | 磁盘使用情况 | 返回(总/已用/空闲) |

### 踩坑指南
| 陷阱 | 说明 |
|------|------|
| os.rename跨磁盘 | 只能在同文件系统内用 | 用shutil.move |
| rmtree无法恢复 | 删除后无法恢复 | 操作前先确认 |
| copytree目标存在 | 如果目标目录存在会报错 | 先删除或改用ditto |

### 记忆口诀
> **copy2保留全，move跨磁盘**
> **rmtree危险勿乱用，copytree目标要空缺**

| 符号 | 含义 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | 2024 |

| `%H` | 24小时制 | 14 |
| `%M` | 分钟 | 30 |
| `%S` | 秒 | 59 |

### timedelta 参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `days` | 天 | `timedelta(days=1)` |
| `hours` | 小时 | `timedelta(hours=2)` |
| `minutes` | 分钟 | `timedelta(minutes=30)` |
| `seconds` | 秒 | `timedelta(seconds=10)` |
| `weeks` | 周 | `timedelta(weeks=1)` |
| `.total_seconds()` | 总秒数 | `delta.total_seconds()` |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| **naive vs aware** | 无时区的时间无法比较 | 使用时区：`datetime.now(ZoneInfo(...))` |
| **strftime vs strptime** | 容易搞混 | **f=format(输出), p=parse(输入)** |
| **时间比较陷阱** | naive和aware不能直接比较 | 统一成aware再比较 |
| **时区导入** | Windows需要tzdata | `pip install tzdata` |
| **weekday返回值** | 0是周一，不是周日 | 0-6对应周一到周日 |

### 记忆口诀
> **strftime输出字符串，strptime解析字符串**
> **f=format格式化，p=parse解析**
> **timedelta时间加减，astimezone时区转**
> **naive无时区要避免，aware安全才靠谱**

| `__setstate__(state)` | 定义反序列化时如何恢复 |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| **安全风险** | unpickle不可信数据可执行任意代码 | 永远不要反序列化不可信来源的数据 |
| **文件模式错误** | 必须用二进制模式 | `'wb'`写入, `'rb'`读取 |
| **版本兼容** | 不同Python版本pickle格式可能不同 | 长期存储建议用JSON |
| **lambda无法序列化** | 匿名函数不能被pickle | 改用普通函数 |

### 记忆口诀
> **dump/load文件操作，dumps/loads字节流**
> **二进制模式要记牢，wb写入rb读取**
> **安全警告勿忽视，不可信数据别反序列**

### API 速查

**连接与游标**
| API | 说明 | 示例 |
|-----|------|------|
| `sqlite3.connect(db)` | 连接数据库 | `conn = sqlite3.connect('test.db')` |
| `sqlite3.connect(':memory:')` | 内存数据库 | 不保存文件 |
| `conn.cursor()` | 创建游标 | `cursor = conn.cursor()` |
| `conn.close()` | 关闭连接 | |

**执行SQL**
| API | 说明 | 示例 |
|-----|------|------|
| `cursor.execute(sql, params)` | 执行单条SQL | `execute('SELECT * WHERE id=?', (1,))` |
| `cursor.executemany(sql, seq)` | 批量执行 | `executemany('INSERT ...', [...])` |
| `cursor.executescript(script)` | 执行多条SQL | 用分号分隔的多条语句 |

**事务控制**

| API | 说明 |
|-----|------|
| `conn.commit()` | 提交更改 |
| `conn.rollback()` | 回滚更改 |

**获取结果**
| API | 说明 |
|-----|------|
| `cursor.fetchone()` | 获取下一行(元组或None) |
| `cursor.fetchmany(n)` | 获取n行 |
| `cursor.fetchall()` | 获取所有剩余行 |

**高级特性**
| API | 说明 |
|-----|------|
| `conn.row_factory = sqlite3.Row` | 字典化访问(通过列名) |
| `row['column_name']` | 通过列名访问 |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| **SQL注入** | 字符串拼接导致安全风险 | 始终用 `?` 占位符 |
| **忘记commit** | 修改不会自动保存 | 增删改后必须commit |
| **占位符格式** | `?` vs `%s` vs `:name` | sqlite3用 `?` 或 `:name` |
| **并发写入** | SQLite同一时间只允许一个写入者 | 高并发考虑PostgreSQL/MySQL |

### 记忆口诀
> **connect连接cursor游标，execute执行SQL**
> **问号占位防注入，executemany批量插**
> **commit提交rollback回滚，fetch获取结果**
> **row_factory字典访问，with语句自动提交**

## 22. time - 时间戳与延时

### 主动回忆

```python
ts = time.___________(struct)  # 答案: mktime

# ... 代码 ...
elapsed = time.perf_counter() - start
```

### API 速查

**基础操作**
| API | 说明 | 示例 |
|-----|------|------|
| `time.time()` | 当前时间戳(浮点数) | `1700000000.123456` |
| `time.sleep(secs)` | 程序暂停 | `time.sleep(2)` |
| `time.ctime([secs])` | 时间戳→可读字符串 | `'Tue Oct 10 16:00:00 2023'` |

**时间转换**
| API | 说明 | 示例 |
|-----|------|------|
| `time.localtime([ts])` | 时间戳→本地struct_time | 本地时区 |
| `time.gmtime([ts])` | 时间戳→UTC struct_time | UTC时区 |
| `time.mktime(t)` | struct_time→时间戳 | 本地时间 |
| `time.strftime(fmt, t)` | struct_time→字符串 | 格式化输出 |
| `time.strptime(s, fmt)` | 字符串→struct_time | 解析字符串 |

**性能计时 (Python 3.3+)**
| API | 说明 | 用途 |
|-----|------|------|
| `time.perf_counter()` | 高精度计时器 | 测量代码运行时长(含sleep) |
| `time.process_time()` | CPU时间 | 只记录CPU运行时间 |

**常用格式符号**
| 符号 | 含义 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | 2024 |
| `%m` | 月份(01-12) | 01 |
| `%d` | 日期(01-31) | 15 |
| `%H` | 24小时制 | 14 |
| `%M` | 分钟 | 30 |
| `%S` | 秒 | 59 |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| **time()测性能** | 受系统时间调整影响 | 用 `perf_counter()` |
| **时区混淆** | localtime vs gmtime | 注意本地/UTC的区别 |
| **strftime vs strptime** | 容易搞混 | **f=format(输出), p=parse(解析)** |
| **sleep精度** | 不保证精确到毫秒 | 实际可能略长 |

### 记忆口诀
> **time时间戳，sleep程序暂停**
> **localtime本地时，gmtime UTC**
> **mktime转时间戳，strftime格式化输出**
> **strptime解析字符串，perf_counter测性能**
> **f是format输出，p是parse解析**

## 综合记忆卡片

### 模块关系图
```
文件操作: pathlib(路径) + shutil(复制删除) + os(系统接口)

迭代器工具: itertools(chain/groupby/islice/combinations/product)
高阶函数: functools(lru_cache/partial/wraps/reduce/singledispatch)
数学计算: math(常数/取整/幂对数/三角函数/组合数论)
统计分析: statistics(平均数/中位数/众数/标准差/分位数/相关回归)
解释器接口: sys(argv/path/exit/platform/version_info/getsizeof/标准流)
进程管理: subprocess(run执行命令/Popen异步控制/管道通信)

多线程并发: threading(Thread/Lock/RLock/Condition/Semaphore/Event)

轻量数据库: sqlite3(connect/cursor/execute/fetch/commit)
```

- **s结尾** = 操作字符串：`json.dumps()`, `json.loads()`, `strptime()`

- **递归** = r开头：`rglob()`, `rmtree()`
