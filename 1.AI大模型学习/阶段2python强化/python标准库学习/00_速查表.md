## 1. pathlib - 现代路径操作

### 主动回忆
```python
# Q1: 创建路径并拼接子目录
p = Path("data") ___________ "subdir"  # 答案: /

# Q2: 递归查找所有.py文件
files = Path(".").___________("*.py")  # 答案: rglob

# Q3: 快速读写小文件
content = p.___________()  # 答案: read_text
p.___________("content")  # 答案: write_text

# Q4: 获取文件名(无后缀)
name = p.___________  # 答案: stem
```

### API 速查

| API | 说明 | 示例 |
|-----|------|------|
| `Path(path)` | 创建路径对象 | `p = Path("data/file.txt")` |
| `p / "sub"` | 路径拼接 | `Path("home") / "user"` |
| `p.name` | 完整文件名 | `"file.txt"` |
| `p.stem` | 主文件名(无后缀) | `"file"` |
| `p.suffix` | 扩展名 | `".txt"` |
| `p.parent` | 父目录 | `Path("data")` |
| `p.exists()` | 是否存在 | |
| `p.is_file()` | 是否是文件 | |
| `p.is_dir()` | 是否是目录 | |
| `p.iterdir()` | 遍历目录(生成器) | |
| `p.glob("*.py")` | 非递归查找 | |
| `p.rglob("*.py")` | 递归查找 | |
| `p.read_text()` | 读文件 | |
| `p.write_text()` | 写文件 | |
| `p.mkdir(parents=True)` | 创建目录(含父目录) | |
| `p.unlink()` | 删除文件 | |

### 踩坑指南
| 陷阱 | 说明 | 正确做法 |
|------|------|----------|
| 字符串路径混用 | `Path("dir") + "file"` ❌ | 用 `/` 拼接 |
| iterdir返回值 | 不是字符串，是Path对象 | 用 `f.name` 获取字符串 |
| read_text大文件 | 会全部加载到内存 | 大文件用 `with p.open()` |
| glob结果类型 | 返回生成器，不是列表 | 用 `list()` 转换或直接遍历 |

## 2. shutil - 高级文件操作

### 主动回忆
```python
# Q1: 复制文件(保留元数据)
shutil.___________(src, dst)  # 答案: copy2

# Q2: 递归删除非空目录
shutil.___________(path)  # 答案: rmtree

# Q3: 跨磁盘移动文件
shutil.___________(src, dst)  # 答案: move
```

### API 速查

| API | 说明 | 注意 |
|-----|------|------|
| `shutil.copy2(src, dst)` | 复制+保留元数据 | 比copy更完整 |
| `shutil.copy(src, dst)` | 仅复制内容 | 不保留元数据 |
| `shutil.move(src, dst)` | 移动/重命名 | 可跨文件系统 |
| `shutil.rmtree(path)` | 递归删除目录 | 危险操作! |
| `shutil.copytree(src, dst)` | 递归复制目录 | dst必须不存在 |
| `shutil.disk_usage(path)` | 磁盘使用情况 | 返回(总/已用/空闲) |

### 踩坑指南
| 陷阱 | 说明 |
|------|------|
| os.rename跨磁盘 | 只能在同文件系统内用 | 用shutil.move |
| rmtree无法恢复 | 删除后无法恢复 | 操作前先确认 |
| copytree目标存在 | 如果目标目录存在会报错 | 先删除或改用ditto |

## 3. json - 数据序列化

### 主动回忆
```python
# Q1: 判断s结尾是字符串还是文件操作
json._________(obj, s)  # 答案: dumps (字符串)
json._________(obj, f)  # 答案: dump (文件)

# Q2: 中文正常显示
json.dumps(data, ensure_ascii=___________)  # 答案: False

# Q3: 格式化输出
json.dumps(data, indent=___________)  # 答案: 4
```

### API 速查

| API | 说明 | 示例 |
|-----|------|------|
| `json.dumps(obj)` | Python→JSON字符串 | `s = json.dumps({"a": 1})` |
| `json.loads(s)` | JSON字符串→Python | `obj = json.loads(s)` |
| `json.dump(obj, f)` | 写入文件 | `json.dump(data, f)` |
| `json.load(f)` | 读取文件 | `data = json.load(f)` |

**常用参数：**
- `ensure_ascii=False` - 中文正常显示
- `indent=4` - 美化输出
- `default=str` - 自定义序列化函数

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| datetime无法序列化 | JSON默认不支持 | `default=str` 或自定义encoder |
| 中文变\u4e2d\u6587 | ensure_ascii默认True | 设为False |
| loads先读再dump | 别搞混 | dumps/dump配对, loads/load配对 |

## 5. csv - 表格数据

### 主动回忆
```python
# Q1: 读CSV为字典(推荐)
reader = csv.___________(f)  # 答案: DictReader
for row in reader:
    print(row["列名"])

# Q2: 写CSV(自动写表头)
writer = csv.___________(f, fieldnames=["name", "age"])  # 答案: DictWriter
writer.___________()  # 答案: writeheader
writer.writerow({"name": "Tom", "age": 18})

# Q3: 避免空行问题
open("file.csv", newline=___________)  # 答案: ''
```

### API 速查

| API | 说明 |
|-----|------|
| `csv.DictReader(f)` | 读为字典(推荐) |
| `csv.DictWriter(f, fieldnames)` | 写字典(推荐) |
| `writer.writeheader()` | 写入表头 |
| `writer.writerow(row)` | 写单行 |
| `writer.writerows(rows)` | 写多行 |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| Windows多空行 | newline参数问题 | `open(..., newline='')` |
| 编码问题 | 中文乱码 | `encoding='utf-8-sig'` |
| DictReader字段顺序 | 依赖文件首行 | 如需固定用fieldnames |

## 6. re - 正则表达式

### 主动回忆
```python
# Q1: 提取所有数字
nums = re.___________(r"\d+", text)  # 答案: findall

# Q2: 替换手机号中间4位
clean = re.___________(r"(\d{3})\d{4}(\d{4})", r"\1****\2", text)  # 答案: sub

# Q3: 预编译(循环时)
pattern = re.___________(r"\d+")  # 答案: compile

# Q4: 必须用原始字符串
r = _________"\d+"  # 答案: r
```

### API 速查

| API | 说明 |
|-----|------|
| `re.search(pattern, s)` | 扫描全部，首个匹配 |
| `re.match(pattern, s)` | 只从开头匹配(少用) |
| `re.findall(pattern, s)` | 所有匹配(列表) |
| `re.finditer(pattern, s)` | 所有匹配(迭代器) |
| `re.sub(pattern, repl, s)` | 替换 |
| `re.compile(pattern)` | 预编译 |

### 常用符号

| 符号 | 含义 |
|------|------|
| `\d` | 数字 |
| `\w` | 字母数字下划线 |
| `\s` | 空白 |
| `.` | 任意字符(除换行) |
| `*` | 0次或多次 |
| `+` | 1次或多次 |
| `?` | 0次或1次 |
| `[]` | 字符集 |
| `()` | 分组 |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| 贪婪匹配 | `.*` 会匹配尽可能多 | 用`.*?`非贪婪 |
| 忘原始字符串 | `"\\d"` 需要双重转义 | 始终用r"\d" |
| match vs search | match只从开头匹配 | 大部分用search |

## 7. random - 随机数

### 主动回忆
```python
# Q1: 随机选1个
item = random.___________([1, 2, 3])  # 答案: choice

# Q2: 无放回抽样3个
items = random.___________([1,2,3,4,5], k=3)  # 答案: sample

# Q3: [1, 100]随机整数
n = random.___________(1, 100)  # 答案: randint

# Q4: 密码学安全随机
import secrets
token = secrets.___________(16)  # 答案: token_hex
```

### API 速查

| 分类 | API | 说明 |
|------|-----|------|
| 整数 | `randint(a, b)` | [a, b] 随机整数 |
| 序列 | `choice(seq)` | 随机选1个 |
| | `sample(seq, k)` | 无放回选k个 |
| | `shuffle(list)` | 原地打乱 |
| 浮点 | `random()` | [0.0, 1.0) |
| | `uniform(a, b)` | [a, b] 随机小数 |
| 种子 | `seed(n)` | 固定随机序列 |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| 密码用random | 不安全 | 用secrets模块 |
| sample超范围 | k超过序列长度 | 会ValueError |
| shuffle返回None | 原地操作，不返回 | 不要赋值 |

## 8. string - 字符常量

### 主动回忆
```python
# Q1: 导入所有小写字母
from string import ___________  # 答案: ascii_lowercase

# Q2: 生成随机字母组合
import random
random.choice(string.___________)  # 答案: ascii_letters

# Q3: 使用模板替换
from string import ___________  # 答案: Template
t = Template("Hello, $name")
t.substitute(name="World")  # 答案: substitute
```

### API 速查

| 常量 | 内容 | 用途 |
|------|------|------|
| `ascii_letters` | a-z + A-Z | 随机字符串 |
| `ascii_lowercase` | a-z | 小写字母 |
| `ascii_uppercase` | A-Z | 大写字母 |
| `digits` | 0-9 | 数字 |
| `punctuation` | 标点符号 | 密码字符 |
| `Template` | 字符串模板 | 安全替换 |

### Template 类

| 方法 | 说明 |
|------|------|
| `Template(template)` | 创建模板对象 |
| `.substitute(**mapping)` | 替换占位符(必须存在) |
| `.safe_substitute(**mapping)` | 替换(不存在的保留) |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| Template vs f-string | Template用于用户输入 | f-string用于内部数据 |
| substitute缺失Key | 直接报错 | 用safe_substitute |
| $\$ 转义 | 需要输出$符号 | 用$$ |

## 9. os - 操作系统接口

### 主动回忆
```python
# Q1: 获取环境变量
api_key = os.___________("API_KEY")  # 答案: getenv

# Q2: 递归创建目录(含父目录)
os.___________("a/b/c", exist_ok=True)  # 答案: makedirs

# Q3: 遍历目录树
for root, dirs, files in os.___________("."):  # 答案: walk
    print(root, files)

# Q4: 跨平台路径拼接
path = os.path.___________("dir", "file.txt")  # 答案: path.join

# Q5: 获取当前工作目录
cwd = os.___________()  # 答案: getcwd
```

### API 速查

**环境信息**
| API | 说明 |
|-----|------|
| `os.environ` | 环境变量字典 |
| `os.getenv(key)` | 获取环境变量 |
| `os.name` | 系统类型 (nt/posix) |
| `os.cpu_count()` | CPU核心数 |

**目录操作**
| API | 说明 |
|-----|------|
| `os.getcwd()` | 当前工作目录 |
| `os.chdir(path)` | 切换目录 |
| `os.listdir(path)` | 列出内容(非递归) |
| `os.makedirs(path, exist_ok=True)` | 递归创建 |
| `os.mkdir(path)` | 单级创建 |
| `os.rmdir(path)` | 删除空目录 |

**文件操作**
| API | 说明 |
|-----|------|
| `os.remove(path)` | 删除文件 |
| `os.rename(src, dst)` | 重命名 |
| `os.replace(src, dst)` | 原子重命名 |
| `os.stat(path)` | 文件属性 |

**os.path 路径处理**
| API | 说明 |
|-----|------|
| `os.path.join(p1, p2)` | 智能拼接 |
| `os.path.exists(path)` | 是否存在 |
| `os.path.isfile(path)` | 是否文件 |
| `os.path.isdir(path)` | 是否目录 |
| `os.path.split(path)` | (目录, 文件名) |
| `os.path.splitext(path)` | (文件名, 扩展名) |
| `os.path.abspath(path)` | 绝对路径 |

**目录遍历**
| API | 说明 |
|-----|------|
| `os.walk(path)` | 生成(root, dirs, files)三元组 |

### 踩坑指南
| 陷阱 | 说明 | 解决 |
|------|------|------|
| mkdir vs makedirs | mkdir父目录不存在报错 | 用makedirs+exist_ok |
| rename跨磁盘 | 只能在同文件系统 | 用shutil.move |
| 路径拼接用+ | 不跨平台 | 用os.path.join或pathlib |
| os.walk修改dirs | 需要原地修改 | `dirs[:] = [...]` |

> 注: 现代Python优先用pathlib，os适合环境变量、walk等场景
