## 1. BERT核心架构与原理

### 1.1 模型概述

**BERT**（Bidirectional Encoder Representations from Transformers）是Google AI于2018年10月发布的预训练语言模型，在NLP领域具有里程碑意义。

**核心突破：**

- 机器阅读理解SQuAD 1.1任务中首次超越人类表现
- GLUE基准提升至80.4%（绝对提升7.6%）
- MultiNLI准确度达到86.7%（绝对提升5.6%）
- 在11项NLP任务中均达到SOTA水平



### 1.2 架构设计

#### 1.2.1 宏观结构

![image-20251014102538148](assets/image-20251014102538148.png)

BERT采用**Transformer Encoder**架构，实现真正的双向上下文建模，区别于GPT的单向结构和ELMo的拼接式双向LSTM。

| 模块              | 功能说明                                             |
| :---------------- | :--------------------------------------------------- |
| **Embedding层**   | 将输入文本转为向量表示（Token + Segment + Position） |
| **Transformer层** | 实现双向编码与特征提取（仅Encoder）                  |
| **预微调层**      | 适配不同下游任务的输出层                             |

#### 1.2.2 输入表示

输入嵌入由三种向量**相加**组成：

<img src="assets/BERT2.png" alt="img" style="zoom: 50%;" />

```text
示例：[CLS] my dog is cute [SEP] he likes play##ing [SEP]
```

| 嵌入类型                | 说明                                        |
| :---------------------- | :------------------------------------------ |
| **Token Embeddings**    | 词向量，首 token `[CLS]` 用于分类任务       |
| **Segment Embeddings**  | 区分句子A/B，服务于句子对任务               |
| **Position Embeddings** | 可学习的位置编码（非Transformer三角函数式） |



#### 1.2.3 预微调模块（Fine-tuning）

- 经过中间层Transformer的处理后，BERT的最后一层根据任务的不同需求而做不同的调整即可。
- 比如对于sequence-level的分类任务, BERT直接取第一个`[CLS]` token 的final hidden state, 再加一层全连接层后进行softmax来预测最终的标签。

> 对于不同的任务, 微调都集中在预微调模块, 几种重要的NLP微调任务架构图展示如下



<img src="assets/BERT3.png" alt="img" style="zoom:50%;" />

| 任务类型       | 处理方式                   |
| -------------- | -------------------------- |
| **句子对分类** | 取 `[CLS]` 向量 + 全连接层 |
| **单句分类**   | 同上                       |
| **问答任务**   | 预测答案起止位置           |
| **序列标注**   | 对每个 token 进行分类      |

> - 从上图中可以发现, 在面对特定任务时, 只需要对预微调层进行微调, 就可以利用Transformer强大的注意力机制来模拟很多下游任务, 并得到SOTA的结果. (句子对关系判断, 单文本主题分类, 问答任务(QA), 单句贴标签(NER))
> - 若干可选的超参数建议如下：
>
> | 参数                  | 建议值           |
> | :-------------------- | :--------------- |
> | Batch Size            | 16 或 32         |
> | Learning Rate（Adam） | 5e-5, 3e-5, 2e-5 |
> | Epochs                | 3 或 4           |



### 1.3 BERT的预训练任务

BERT 通过两个无监督任务进行预训练，提升其对语言的理解能力：

- 任务一: Masked LM (带mask的语言模型训练)
- 任务二: Next Sentence Prediction (下一句话预测任务)



#### ✅ 任务一：**Masked Language Model（Masked LM）**

🔍 目标：

训练模型**理解双向上下文**，解决传统语言模型只能单向或拼接建模的问题。



🧪 操作流程：

- **随机抽取 15% 的 token** 作为预测目标

- 对这些 token 进行以下三种处理之一：

  | 处理方式        | 概率 | 示例                                   |
  | :-------------- | :--- | :------------------------------------- |
  | 替换为 `[MASK]` | 80%  | `my dog is hairy` → `my dog is [MASK]` |
  | 替换为随机词    | 10%  | `my dog is hairy` → `my dog is apple`  |
  | 保持不变        | 10%  | `my dog is hairy` → `my dog is hairy`  |

- 模型根据上下文预测这些被处理的 token



💡 设计亮点：

- 模型**无法确定**哪些词被替换或掩盖，从而**强制学习上下文语义**
- 仅对 15% 的 token 操作，**不会破坏语言整体结构**



#### ✅ 任务二：**Next Sentence Prediction（NSP）**

🔍 目标：

让模型**理解句子间的关系**，为下游任务（如 QA、NLI）提供语义连贯性判断能力。



🧪 操作流程：

1. 输入句子对 (A, B)

2. 模型判断 B 是否为 A 的真实下一句

   | 类型       | 比例 | 标签                |
   | :--------- | :--- | :------------------ |
   | 真实下一句 | 50%  | `IsNext`（正样本）  |
   | 随机句子   | 50%  | `NotNext`（负样本） |



📈 效果：

- 在测试集上可达到 **97%~98% 的准确率**
- 显著增强模型对**句子间逻辑关系**的理解能力



## 2 BERT模型特点

### 2.1 BERT模型优缺点

**✅ 一、BERT 的优点**

| 优点                 | 说明                               |
| :------------------- | :--------------------------------- |
| **SOTA 性能**        | 在 11 项 NLP 任务中取得最优结果    |
| **基于 Transformer** | 并行计算能力强，能捕捉长距离依赖   |
| **双向上下文建模**   | 使用 Encoder 实现真正的双向表示    |
| **微调灵活**         | 预训练后适配多种下游任务，扩展性强 |



**⚠️ 二、BERT 的缺点**

| 缺点                 | 说明                                                         |
| :------------------- | :----------------------------------------------------------- |
| **模型庞大**         | 参数多，推理慢，不适合资源受限场景                           |
| **中文以字为 token** | 无法利用词向量，难以处理生僻词（被替换为 `[UNK]`）           |
| **训练/预测不一致**  | `[MASK]` 只在训练中出现，预测阶段缺失，带来偏差              |
| **收敛慢**           | 按照BERT的MLM任务中的约定，每个 batch 仅 15% token 参与训练，效率低 |

> BERT目前给出的中文模型中，是以字为基本token单位的，很多需要词向量的应用无法直接使用。



### 2.2 BERT的MLM 任务中的 80%-10%-10% 策略

**❓ 为什么不是 100% `[MASK]`？**

- 如果全部 mask，模型在微调阶段从未见过原始词，导致**信息缺失**
- 保留部分原始词（10%）让模型看到**真实语言面貌**

**❓ 为什么加入 10% 随机词？**

- 防止模型“**死记硬背**”当前 token
- 强迫模型结合上下文进行**语义建模**，提升泛化能力



**✅ 总结策略作用：**

| 比例 | 处理方式        | 目的                       |
| :--- | :-------------- | :------------------------- |
| 80%  | 替换为 `[MASK]` | 学习上下文预测能力         |
| 10%  | 替换为随机词    | 防止模型偷懒、死记硬背     |
| 10%  | 保持原词        | 保留真实语义信息，避免偏差 |



### 2.3 BERT 处理长文本的方法

> ⚠️ **BERT**预训练模型所接收的最大sequence长度是512，所以BERT 最大输入长度为 **512 token**（含 `[CLS]` 和 `[SEP]`）

**三种截断策略：**

| 策略            | 描述                                                | 适用场景                         |
| :-------------- | :-------------------------------------------------- | :------------------------------- |
| **Head-only**   | 保留前 510 个 token(要留两个位置给`[CLS]`和`[SEP]`) | 开头信息更重要，如新闻标题       |
| **Tail-only**   | 保留后 510 个 token                                 | 结尾信息更关键，如法律文书       |
| **Head + Tail** | 保留前 128 + 后 382（或前 256 + 后 254）            | 综合前后关键信息，适合大多数文本 |

> head+only方式：选择前128个token和最后382个token (文本总长度在800以内)。 或者前256个token和最后254个token (文本总长度大于800)。



## 3. BERT系列演进模型

### 3.1 ALBERT：轻量高效优化

#### 核心优化点

| 序号 | 优化项           | 技术方案                      | 效果                   |
| :--- | :--------------- | :---------------------------- | :--------------------- |
| 1    | **词嵌入分解**   | 低维投影（128维）→隐藏层      | 参数量从2300万降至48万 |
| 2    | **跨层参数共享** | 所有Transformer层共享参数     | 参数量降至1/12~1/24    |
| 3    | **替换NSP为SOP** | Sentence Order Prediction任务 | 增强语序建模能力       |
| 4    | **移除Dropout**  | 训练100万batch后仍未过拟合    | 意外提升下游任务效果   |
| 5    | **MLM任务优化**  | 长句子训练+Masked N-gram LM   | 提升上下文信息利用     |

#### 关键技术细节

**词嵌入分解**：将词表矩阵分解为`vocab×128` + `128×hidden`，参数减少98%。

**参数共享**：12层共享同一套注意力与前馈网络参数，大幅提升训练稳定性。

**SOP任务**：预测句子A、B是否为正常顺序（正样本）或逆序（负样本），比NSP更具挑战性。

**MLM优化**：

- **长句子训练**：90% steps使用512长度（vs BERT仅10%）
- **N-gram Masking**：预测连续片段，1/2/3-gram占比40%/30%/20%/10%

### 3.2 RoBERTa：鲁棒性优化

**发布信息**：Facebook & 华盛顿大学，2019年提出，架构与BERT一致，聚焦训练策略优化。

| 优化维度       | BERT               | RoBERTa                                         |
| :------------- | :----------------- | :---------------------------------------------- |
| **训练数据**   | 16GB               | 160GB（Books+Wiki+CC-News+OpenWebText+Stories） |
| **Batch Size** | 256                | 最大8000                                        |
| **训练步数**   | 较短               | 更长，充分学习                                  |
| **NSP任务**    | 保留               | **完全移除**                                    |
| **Mask策略**   | 静态（预处理一次） | **动态（每次输入随机）**                        |
| **分词方式**   | char-level BPE     | **byte-level BPE**（词表5万）                   |

**NSP消融实验结论**：

1. Segment-pair + NSP（原始BERT）< 
2. Sentence-pair + NSP < 
3. Full-sentences（无NSP，可跨文档）< 
4. **Document-sentences（无NSP，不跨文档）**

💡 **核心发现**：NSP任务对大型模型起负面作用，使用单文档连续句子训练效果最佳。

### 3.3 MacBERT：中文场景专项优化

**发布信息**：哈工大NLP实验室，2020年11月提出，专注中文NLP任务。

| 优化点       | 技术方案                                          |
| :----------- | :------------------------------------------------ |
| **MLM改进**  | Word2Vec相似词替换`[MASK]`，解决exposure bias问题 |
| **Mask策略** | 全词+N-gram mask（1~4字占比40%/30%/20%/10%）      |
| **NSP替换**  | 采用SOP任务（借鉴ALBERT）                         |

**相似词替换**：80%概率替换为近义词，10%随机词，10%保留原词，预测目标不变。

### 3.4 SpanBERT：连续片段建模

**核心贡献**：

1. **Span Masking**：随机遮掩连续片段（平均长度3.8 token）
2. **SBO任务**：Span Boundary Objective增强片段边界表示
3. **NSP反思**：单句训练 > 句子对训练

**Span Masking算法**：

1. 按几何分布随机选择span长度
2. 按均匀分布随机选择起始位置
3. 直接mask该连续片段

**SBO机制**：利用Span边界两个词的向量+被mask词的位置向量，预测原始词，损失与MLM联合训练。

## 4. ELMo模型

**核心思想**：基于上下文的动态词向量调整，解决多义词问题。

**架构**：双向双层LSTM

1. **Embedding层**：生成静态词向量
2. **双向LSTM层**：分别建模前后文
3. **特征融合层**：加权融合各层表示

**预训练流程**：

- **阶段一**：语言模型预训练，获得基础向量与LSTM网络
- **阶段二**：上下文输入LSTM，生成融合语境的动态词向量

## 5. GPT模型

**本质**：OpenAI提出的**单向**语言模型，采用Transformer Decoder架构。

**架构改造**：

- 删除encoder-decoder attention子层
- 仅保留Masked Multi-Head Attention + Feed Forward
- 12层Decoder Block堆叠

**训练范式**：

1. **无监督预训练**：利用前文预测当前词
2. **有监督微调**：适配下游任务

## 6. 三大模型对比总结

| 对比维度       | BERT                | GPT                 | ELMo                 |
| :------------- | :------------------ | :------------------ | :------------------- |
| **特征提取器** | Transformer Encoder | Transformer Decoder | 双向LSTM             |
| **语言模型**   | **真正双向**        | **单向**            | 双向（拼接两个单向） |
| **上下文建模** | 同时利用前后文      | 仅利用前文          | 分别建模后拼接       |
| **预训练任务** | MLM + NSP/SOP       | 自回归语言模型      | 双向语言模型         |
| **核心优势**   | 双向语义理解        | 生成能力强          | 动态词向量           |

⚠️ **关键区别**：BERT的双向性是**同时进行**，ELMo是**分别训练后拼接**，GPT则是**纯单向**。
