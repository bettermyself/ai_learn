# Day 18 学习笔记 - 2026-01-27

## 今日主题
移动零与相对顺序保持

## 核心知识点

### 1. 保持相对顺序的概念

| 操作方式 | 结果示例 | 非零元素顺序 |
|:---------|:---------|:------------|
| **保持相对顺序** | `[1, 3, 12, 0, 0]` | 1→3→12（原顺序） |
| **不保持相对顺序** | `[12, 3, 1, 0, 0]` | 12→3→1（打乱） |

**LeetCode 283 要求**：必须保持非零元素的相对顺序！

### 2. 快慢指针交换法（保持顺序）

```python
slow = 0
for fast in range(len(nums)):
    if nums[fast] != 0:
        nums[slow], nums[fast] = nums[fast], nums[slow]
        slow += 1
```

**核心逻辑**：
- fast 从左到右扫描，依次找到非零元素
- 每找到一个就"抄"到 slow 位置
- 交换操作把 0 "挤"到后面

### 3. 为什么对撞指针不适用？

对撞指针通过交换会把右边（后面）的元素换到前面，**破坏了相对顺序**：
```python
# 对撞指针会破坏顺序，不适用于本题
left, right = 0, len(nums) - 1
while left <= right:
    if nums[left] == 0:
        nums[left], nums[right] = nums[right], nums[left]  # 把后面的换到前面！
        right -= 1
    else:
        left += 1
```

### 4. 交换法 vs 补0法

| 方法 | 循环次数 | 交换次数 | 适用场景 |
|:-----|:---------|:---------|:---------|
| 交换法 | 1次 | 等于非零元素个数 | 通用，代码简洁 |
| 补0法 | 2次 | 等于非零元素个数 | 当0很多时写操作更少 |

### 5. 小优化：避免无意义交换

```python
if nums[fast] != 0:
    if fast != slow:  # 只在位置不同时才交换
        nums[slow], nums[fast] = nums[fast], nums[slow]
    slow += 1
```

当 `fast == slow` 时，交换是自己换自己，没有实际意义。

## 题目练习

### LeetCode 283：移动零

**题目描述**：原地移动所有 0 到末尾，保持非零元素相对顺序

**解法**：
```python
class Solution:
    def moveZeroes(self, nums: List[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1
```

**复杂度分析**：
- 时间复杂度：O(n)
- 空间复杂度：O(1)

## 理解检查记录

**问题1**：为什么快慢指针能保持相对顺序，而对撞指针会破坏顺序？
- **回答**：快慢指针通过快指针有顺序的找到非零的元素，通过慢指针保存好非零元素，所以是有顺序的；而对撞指针通过交换左指针找到的零元素，从而破坏顺序
- **评价**：✅ 正确

**问题2**：为什么最后还需要补0？能否在主循环中直接完成？
- **回答**：通过slow指针保存非零元素，当fast指针遍历结束后，slow指针指向的索引是非零元素的个数-1，所以还需要一个循环把剩余位置补0；可以在主循环直接完成
- **评价**：✅ 正确（补充：交换法更优雅，不需要补0）

**问题3**：把偶数移到后面，保持奇数顺序，核心判断条件？
- **代码**：
  ```python
  slow = 0
  for fast in range(len(nums)):
      if nums[fast] % 2 == 1:
          nums[slow], nums[fast] = nums[fast], nums[slow]
          slow += 1
  ```
- **评价**：✅ 完全正确

**问题4**：数组 `[1, 2, 3, 0, 0]` 会执行几次交换？
- **回答**：3次交换
- **评价**：✅ 正确（虽然前3次是自己换自己）

## 通用模式总结

| 模式 | 条件判断 | 效果 |
|:-----|:---------|:-----|
| 移动零 | `nums[fast] != 0` | 0被挤到后面 |
| 移除偶数 | `nums[fast] % 2 == 1` | 偶数被挤到后面 |
| 通用模板 | `nums[fast] 满足保留条件` | 不满足的自动移到后面 |

**核心思想**：快慢指针 + 交换 = 原地移动元素并保持顺序
