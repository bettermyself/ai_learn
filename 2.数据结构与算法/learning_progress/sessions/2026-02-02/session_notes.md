## 新课部分：LeetCode 16 最接近的三数之和

### 核心知识点

#### 1. 与三数之和的区别

| 维度 | LC 15（三数之和） | LC 16（最接近的三数之和） |
|:-----|:-----------------|:-------------------------|
| 目标 | 找 `a + b + c = 0` | 找 `a + b + c` 最接近 `target` |
| 结果 | 返回所有不重复的组合 | 返回最接近的那个和 |
| 判断方式 | 等于 vs 不等于 | 比较差的绝对值 |

#### 2. 判断标准
```python
# 用绝对值差衡量接近程度
if abs(current_sum - target) < abs(closest - target):
    closest = current_sum
```

#### 3. 更新时机
- **LC 15**：只有 `== target` 时才处理
- **LC 16**：**每次循环**都要判断并更新

#### 4. 提前终止
```python
if current_sum == target:
    return current_sum  # 差值为 0，不可能更接近
```

## 知识点问答记录

### 问题 1：为什么每次都要判断并更新？
**回答**：因为找的是最接近的数，需要求和后每次与 target 计算差值，如果更接近就替换。
**评价**：✅ 完全正确

### 问题 2：如何判断更接近？
**回答**：`if abs(current_sum - target) < abs(closest - target)`
**评价**：✅ 完全正确

### 问题 3：为什么等于时可直接返回？
**回答**：差值为 0，不可能更接近了。
**评价**：✅ 完全正确

### 问题 4：指针移动方向判断？
**回答**：`total > target → right -= 1`（减小和），`total < target → left += 1`（增大和）
**评价**：✅ 完全正确

## 代码实现（优化后）

```python
class Solution:
    def threeSumClosest(self, nums: List[int], target: int) -> int:
        nums.sort()
        closest = nums[0] + nums[1] + nums[2]  # 用前三个数初始化

        for i in range(len(nums) - 2):  # 只需遍历到倒数第三个
            left, right = i + 1, len(nums) - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                # 统一更新，避免重复代码
                if abs(total - target) < abs(closest - target):
                    closest = total

                if total > target:
                    right -= 1
                elif total < target:
                    left += 1
                else:
                    return total  # 精确匹配，直接返回

        return closest
```

## 代码优化点

| 优化项 | 原代码 | 优化后 | 原因 |
|:-------|:-------|:-------|:-----|
| 初始化 | `float('inf')` | `nums[0] + nums[1] + nums[2]` | 更直观 |
| 外层循环 | `range(len(nums))` | `range(len(nums) - 2)` | 避免无效遍历 |
| 更新逻辑 | 重复两次 | 统一提取 | 代码更简洁 |

| 空间 | O(1) | 除排序外只用了常数空间 |

```
3. 根据题目要求更新结果

```
