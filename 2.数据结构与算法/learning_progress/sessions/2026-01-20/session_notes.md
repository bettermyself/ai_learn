## 核心知识点

### HashSet 的查找特性

**核心操作**：
| 操作 | 时间复杂度 | 说明 |
|:-----|:-----------|:-----|
| `add(x)` | O(1) 平均 | 插入元素 |
| `x in set` | O(1) 平均 | 判断元素是否存在 |
| `remove(x)` | O(1) 平均 | 删除元素（不存在会报错） |
| `discard(x)` | O(1) 平均 | 删除元素（不存在不报错） |

**删除方法对比**：
```python
s = {1, 2, 3, 4, 5}

# remove(x) - 元素不存在会抛出 KeyError
s.remove(3)  # OK
s.remove(99)  # KeyError: 99

# discard(x) - 元素不存在静默忽略
s.discard(4)  # OK
s.discard(99)  # 什么都不发生
```

### 核心模式：从序列起点开始扩展

**问题**：给定无序数组，找到最长的连续数字序列（不需要在原数组中连续位置）。

**核心思路**：
1. 把所有元素放入 HashSet → O(N)
2. 对于每个元素 `num`，判断它是否是**连续序列的起点**
   - 判断方法：如果 `num - 1` **不在** Set 中，说明 `num` 是起点
3. 从起点开始，不断检查 `num + 1`, `num + 2`, ... 是否在 Set 中
4. 记录最长的长度

**为什么从起点开始？**
- 如果从任意点开始扩展，会重复计算
- 例如：序列 `[1, 2, 3, 4]`
  - 从 1 开始：检查 1,2,3,4 → 长度 4
  - 从 2 开始：检查 2,3,4 → 长度 3（重复！）
  - 从 3 开始：检查 3,4 → 长度 2（重复！）
  - 从 4 开始：检查 4 → 长度 1（重复！）
- 只从起点（`num-1` 不存在）开始，每个序列只计算一次

## 题目：LeetCode 128 - 最长连续序列

### 题目描述

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列的长度。
要求时间复杂度为 **O(n)**。

**示例**：
```
输入：nums = [100, 4, 200, 1, 3, 2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]

输入：nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]
输出：9
解释：最长数字连续序列是 [0, 1, 2, 3, 4, 5, 6, 7, 8]
```

---

### 解法分析

#### 暴力解法

```python
# 伪代码
for num in nums:
    length = 1
    while num + length in nums:  # 这里查找是 O(n)
        length += 1
```
- 时间复杂度：O(n²) — `in nums` 是 O(n) 操作
- 空间复杂度：O(1)

#### 优化解法（HashSet + 从起点扩展）

**完整代码**：
```python
from typing import List

class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        result = 0
        set_nums = set(nums)
        for num in set_nums:
            if num - 1 not in set_nums:  # 是起点
                length = 1
                while (num + length) in set_nums:
                    length += 1
                if length > result:
                    result = length
        return result
```

**复杂度分析**：
- 时间复杂度：**O(n)** — 每个元素最多被访问 2 次
- 空间复杂度：**O(n)** — HashSet 存储所有元素

**为什么是 O(n)？**
- 外层 `for` 循环：遍历每个元素
- 内层 `while` 循环：**只有起点才会进入**
- 每个元素在整个过程中最多被访问 **1 次**（外层）+ **1 次**（内层扩展）= **2 次**
- 所以总操作次数 ≈ 2n，即 O(n)

### 算法流程详解

**示例**：`nums = [100, 4, 200, 1, 3, 2]`

```
set_nums = {1, 2, 3, 4, 100, 200}
```

| num | num - 1 | 是起点？ | 扩展结果 | length |
|:---|:--------|:---------|:---------|:-------|
| 1 | 0 不在 | ✅ | 1, 2, 3, 4 | 4 |
| 2 | 1 在 | ❌ | 跳过 | - |
| 3 | 2 在 | ❌ | 跳过 | - |
| 4 | 3 在 | ❌ | 跳过 | - |
| 100 | 99 不在 | ✅ | 100 | 1 |
| 200 | 199 不在 | ✅ | 200 | 1 |

**最终结果**：4（序列 [1, 2, 3, 4]）
