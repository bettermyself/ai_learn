## 一、知识点讲解

### 1. 什么是逆波兰表达式？

**逆波兰表达式**（Reverse Polish Notation, RPN），也叫**后缀表达式**，是一种不需要括号的数学表达式写法。

| 表达式类型 | 示例 | 特点 |
|-----------|------|------|
| 中缀表达式（我们习惯的） | `3 + 4 × 2` | 需要括号和运算符优先级 |
| 后缀表达式（逆波兰） | `3 4 2 × +` | 不需要括号，从左到右计算 |

### 2. 核心算法

用**栈**来求解：

1. 遍历 tokens
2. 遇到**数字** → 入栈
3. 遇到**运算符** → 弹出两个元素，计算，将结果入栈
4. 最终栈顶元素即为答案

### 3. 关键细节

- **弹出顺序**：先弹出右操作数，后弹出左操作数
- 对于减法和除法：`a - b` 应该是 `后弹出的 - 先弹出的`
- 除法向零截断：`int(a / b)`

### 4. 示例

计算 `["2", "1", "+", "3", "*"]`：

| 步骤 | 操作 | 栈 |
|------|------|-----|
| 1 | 2 入栈 | [2] |
| 2 | 1 入栈 | [2, 1] |
| 3 | + 弹出1,2，计算2+1=3 | [3] |
| 4 | 3 入栈 | [3, 3] |
| 5 | * 弹出3,3，计算3×3=9 | [9] |

## 二、知识点问答记录

### 问题1：中缀表达式 `(4 + 5) × 2` 对应的后缀表达式是什么？

**回答**：`4, 5, +, 2, *`

**判断**：✅ 正确

### 问题2：计算 `["4", "13", "5", "/", "+"]`，逐步写出栈的变化

**回答**：
- "4" → stack=[4]
- "13" → stack=[4, 13]
- "5" → stack=[4, 13, 5]
- "/" → 弹出5和13，计算13/5=2.6，stack=[4, 2.6]
- "+" → 弹出2.6和4，计算4+2.6=6.6，stack=[6.6]

**判断**：✅ 正确

### 问题3：减法和除法为什么要关注弹出顺序？

**回答**：因为减法和除法，运算符左右操作数顺序很重要，顺序不一致，结果不一致

**判断**：✅ 正确

### 问题4：逆波兰表达式求值的核心思路是什么？

**回答**：碰到运算符，则弹出两个元素计算，将结果压入栈

**判断**：✅ 正确

## 三、代码实现（字典优化版）

```python
class Solution:
    def evalRPN(self, tokens: List[str]) -> int:
        stack = []
        mapping = {
            "+": lambda pre_num, post_num: pre_num + post_num,
            "-": lambda pre_num, post_num: pre_num - post_num,
            "*": lambda pre_num, post_num: pre_num * post_num,
            "/": lambda pre_num, post_num: int(pre_num / post_num),
        }

        for token in tokens:
            if token in mapping:
                post_num, pre_num = stack.pop(), stack.pop()
                stack.append(mapping[token](pre_num, post_num))
            else:
                stack.append(int(token))

        return stack[-1]
```

### 复杂度分析

| 指标 | 复杂度 | 原因 |
|------|--------|------|
| 时间 | O(n) | 遍历一次 tokens |
| 空间 | O(n) | 栈最多存储 n/2 个元素 |

## 四、学习总结

1. **后缀表达式**：无需括号，从左到右顺序计算
2. **栈的作用**：存储中间结果，遇到运算符时取出计算
3. **弹出顺序**：先右后左，对减法/除法至关重要
4. **字典优化**：用 lambda 映射运算符，代码简洁优雅

### 复习问题3：为什么代码中除法要写成 `int(a / b)` 而不是 `a // b`？

- `int(-7/3) = -2`（向零截断）

**判断**：✅ 正确，理解了两种除法的区别

### 复习问题4：栈 `[4, 5]`（5是栈顶），遇到 `-` 运算符，结果是多少？
