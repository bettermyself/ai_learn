## 核心知识点

### 1. 贪心算法核心思想

| 特征 | 描述 |
|:-----|:-----|
| **核心** | 每一步选择当前看来最优的方法 |
| **策略** | 抛弃绝对无用的选择，只保留可能有用的选择 |
| **与暴力的区别** | 不是全盘遍历，通过每步最优解试图得到全局最优 |
| **时间复杂度** | 通常更低（O(n) vs O(n²)） |

### 2. 双指针 + 贪心策略（Container With Most Water）

**初始状态**：
- `left = 0, right = len(height) - 1`
- 两端宽度最大，为初始最大宽度

**每一步决策**：
```python
area = min(height[left], height[right]) * (right - left)
max_area = max(max_area, area)

# 贪心：移动较矮的一边（它是当前面积的瓶颈）
if height[left] < height[right]:
    left += 1
else:
    right -= 1
```

**为什么移动较矮的一边？**

| 移动方向 | 结果分析 |
|:---------|:---------|
| 移动高板 | 距离变小，高度仍受限于矮板 → 面积**绝对不会变大**（100%无效）|
| 移动矮板 | 距离变小，但可能遇到更高的板 → 面积**可能变大**（至少有希望）|

**终止条件**：`left >= right`

### 3. 贪心策略的数学证明（直观理解）

设当前状态为 `(i, j)`，高度为 `h[i] < h[j]`：

- 移动 j：任何 `(i, k)` 都有 `k < j`，距离变小，且 `min(h[i], h[k]) ≤ h[i]`
- 移动 i：可能找到 `h[k] > h[i]`，补偿距离损失

因此：**移动矮的一边是唯一有希望的选择。**

## 题目练习

### LeetCode 11：盛最多水的容器

**题目描述**：给定数组 `height`，找出两条线与 x 轴构成的容器能容纳最多的水。

**解法**：
```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        max_area = 0

        while left < right:
            min_height = min(height[left], height[right])
            area = min_height * (right - left)
            max_area = max(max_area, area)

            if min_height == height[left]:
                left += 1
            else:
                right -= 1

        return max_area
```

**复杂度分析**：
- 时间复杂度：O(n) —— 每个元素最多被访问一次
- 空间复杂度：O(1) —— 只用了常数额外空间

**手动验证**（示例 `[1,8,6,2,5,4,8,3,7]`）：

| left | right | h[left] | h[right] | 面积 | 移动 |
|:----:|:-----:|:-------:|:--------:|:----:|:----:|
| 0 | 8 | 1 | 7 | 1×8=8 | 左 |
| 1 | 8 | 8 | 7 | 7×7=49 | 右 |
| 1 | 7 | 8 | 3 | 3×6=18 | 右 |
| ... | ... | ... | ... | ... | ... |

最大面积 = **49** ✓

## 理解检查记录

**问题1**：位置0（高度1）和位置8（高度7）形成的容器面积？
- **回答**：min(1, 7) × (8-0) = 8
- **评价**：✅ 正确

**问题2**：下一步应该移左指针还是右指针？为什么？
- **回答**：移动左指针，因为左边高度1是瓶颈，移动它才可能遇到更高的板
- **评价**：✅ 正确

**问题3**：贪心算法的核心思想是什么？与暴力枚举的区别？
- **回答**：选择当前看来最优的方法（抛弃无用选择），不是全盘遍历，通过每步最优解试图得到全局最优，时间复杂度更低
- **评价**：✅ 完全正确

**问题4**：暴力法如何做？时间复杂度？
- **回答**：两层遍历找出每一对元素之间的水量，O(n²)
- **评价**：✅ 正确

**问题5**：双指针初始位置？
- **回答**：数组两端，因为宽度最大
- **评价**：✅ 正确

**问题6**：指针移动的终止条件？
- **回答**：left < right
- **评价**：✅ 正确

**深度思考问题**：假如移动后高度更低，为何还要移动矮边？
- **回答**：正确理解：移动高板绝对无益，移动矮板至少有希望
- **评价**：✅ 深刻理解了贪心的本质
