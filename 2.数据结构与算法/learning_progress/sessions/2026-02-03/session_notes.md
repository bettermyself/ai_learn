### 题目：LeetCode 643 - 子数组最大平均数 I

**题目描述：**
找出平均数最大的长度为 k 的连续子数组

**关键洞察：**
- k 是固定常数，最大化平均数 = 最大化窗口和

**学生代码实现：**
```python
class Solution:
    def findMaxAverage(self, nums: List[int], k: int) -> float:
        max_total, total = sum(nums[:k]), sum(nums[:k])
        for i in range(1, len(nums)-k+1):
            total = total - nums[i-1] + nums[i+k -1]
            if total > max_total:
                max_total = total
        return max_total/k
```

**复杂度分析：**
- 时间复杂度：O(n)
- 空间复杂度：O(1)
