## 📚 今日主题：有序数组的威力

### 知识点讲解

#### 有序数组的特性
当数组**有序**时，我们获得了一个极其强大的特性：**方向性（单调性）**。

- **升序数组**：左边小，右边大
- **降序数组**：左边大，右边小
- **核心价值**：单调性 → 确定性决策

#### 对比：有序 vs 无序的两数之和

| 特性 | 无序数组 (LeetCode 1) | 有序数组 (LeetCode 167) |
|:-----|:---------------------|:------------------------|
| **可用解法** | 哈希表补数查找 | 双指针对撞 |
| **时间复杂度** | O(n) | O(n) |
| **空间复杂度** | O(n) | **O(1)** ⭐ |
| **核心思想** | 用空间换时间 | 用有序性换空间 |

#### 对撞指针决策逻辑（升序）

```
nums[left] + nums[right] 与 target 的比较：
  ├─ sum < target  → 需要更大的和 → left += 1（选更大的左值）
  ├─ sum > target  → 需要更小的和 → right -= 1（选更小的右值）
  └─ sum == target → 找到答案 → 返回索引
```

**为什么能确定性移动？**
- 因为数组有序，我们知道移动某个指针后，和会变大还是变小
- 无序数组无法预测，所以不能用双指针

## 🎯 今日题目：LeetCode 167. 两数之和 II

### 题目描述
给定一个已按**非递减顺序排列**的整数数组 `numbers`，找出满足相加之和等于 `target` 的两个数。
- 下标从 **1** 开始
- 假设每个输入只对应唯一答案
- 不能重复使用相同元素

**示例**：
- 输入：`numbers = [2,7,11,15]`, `target = 9`
- 输出：`[1,2]`（因为 `numbers[0] + numbers[1] = 9`）

### 学生的思考过程

#### 知识点问答验证
1. **问**：为什么有序数组能"确定性"移动指针？
   **答**：因为有单调性，能判断指针移动后和的变化趋势

2. **问**：`sum > target` 时移动哪个指针？
   **答**：右指针左移，因为需要降低和

3. **问**：空间复杂度对比？
   **答**：双指针 O(1)，哈希表 O(n)

#### 算法设计思路

**初始化**：
- `left = 0`（最小值）
- `right = len(numbers) - 1`（最大值）

**循环条件**：
- `left < right`（两个指针不能相遇或交叉）

**指针移动**：
- `sum < target` → `left += 1`（增大和）
- `sum > target` → `right -= 1`（减小和）
- `sum == target` → 返回 `[left+1, right+1]`（注意下标从1开始）

### 最终代码实现

```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        left, right = 0, len(numbers) - 1
        while left < right:
            total = numbers[left] + numbers[right]
            if total < target:
                left += 1
            elif total > target:
                right -= 1
            else:  # total == target
                return [left + 1, right + 1]
```

### 复杂度分析
| 指标 | 复杂度 | 说明 |
|:-----|:-------|:-----|
| 时间 | O(n) | 每次循环至少移动一个指针，最多 n-1 次 |
| 空间 | O(1) | 只用了两个指针变量 |
