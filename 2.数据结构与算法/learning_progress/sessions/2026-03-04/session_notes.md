**主题**：辅助栈设计

## 一、知识点讲解

### 1. 辅助栈核心思想

用一个额外的栈来记录主栈的某种"统计信息"，使得我们能在 O(1) 时间内获取这个信息。

### 2. 最小栈问题

设计一个栈，支持以下操作，且**所有操作的时间复杂度都必须是 O(1)**：

| 操作 | 说明 |
|------|------|
| `push(val)` | 将元素压入栈 |
| `pop()` | 弹出栈顶元素 |
| `top()` | 获取栈顶元素 |
| `getMin()` | 获取栈中的最小值 |

**挑战**：普通栈的 `push/pop/top` 都是 O(1)，但 `getMin` 需要遍历整个栈，是 O(n)。

### 3. 解决方案：双栈法

- **主栈 `stack`**：正常存储所有元素
- **辅助栈 `min_stack`**：存储"每个位置对应的最小值"

**关键规则**：
- 每次 `push(x)` 时，`min_stack` 也压入 **当前的最小值**（`min(x, min_stack[-1])`）
- 每次 `pop()` 时，`min_stack` 也跟着弹出
- 这样 `min_stack[-1]` 永远是当前栈中的最小值

### 4. 为什么单个变量不行？

用单个变量记录最小值，当 `pop()` 把最小值弹出后，无法知道新的最小值是什么。

### 5. 手动模拟示例

执行 `push(5)`, `push(3)`, `push(7)`：

| 操作 | stack | min_stack |
|------|-------|-----------|
| `push(5)` | [5] | [5] |
| `push(3)` | [5, 3] | [5, 3] |
| `push(7)` | [5, 3, 7] | [5, 3, 3] |

`getMin()` 返回 `min_stack[-1] = 3`

执行 `pop()` 后：

| 操作 | stack | min_stack |
|------|-------|-----------|
| `pop()` | [5, 3] | [5, 3] |

`getMin()` 返回 `3`

## 二、知识点问答记录

### 问题1：为什么 `getMin` 用一个变量记录最小值不行？

**回答**：用一个变量记录最小值是不行的，因为当栈弹出栈顶元素时，恰好栈顶元素是最小值，那么 `getMin` 无法得知新的最小值。

### 问题2：假设依次执行 `push(5)`, `push(3)`, `push(7)`，`stack` 和 `min_stack` 各自的状态？

**回答**：
- `push(5)`: stack=[5], min_stack=[5]
- `push(3)`: stack=[5,3], min_stack=[5,3]
- `push(7)`: stack=[5,3,7], min_stack=[5,3,3]

### 问题3：接上题，执行 `pop()` 后，`getMin()` 返回什么？

**回答**：stack=[5,3], min_stack=[5,3]，`getMin()` 返回 3

### 问题4：为什么 `min_stack` 的长度始终和 `stack` 相等？

**回答**：因为 `min_stack` 需要和 `stack` 同步变动，所以长度是一致的。这样做的好处是查找效率为 O(1)。

---

## 三、实现方案讨论

### 方案A：双栈法
- 主栈 `stack` + 辅助栈 `min_stack`
- 两栈分离，逻辑清晰

### 方案B：单栈元组法
- 存储元组 `(val, min_val)`
- 元组第一个元素是当前值，第二个是当时的最小值

| 对比项 | 双栈法 | 单栈元组法 |
|--------|--------|------------|
| 空间复杂度 | O(n) | O(n) |
| 代码清晰度 | 两栈分离，逻辑清晰 | 单栈更紧凑 |
| 访问栈顶 | `stack[-1]` | `stack[-1][0]` |
| 获取最小值 | `min_stack[-1]` | `stack[-1][1]` |

**结论**：两种方法空间复杂度相同，都是有效解法。

## 四、代码实现（双栈法 - Python）

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val: int) -> None:
        self.stack.append(val)
        self.min_stack.append(min(val, self.min_stack[-1] if self.min_stack else val))

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
```

### 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| `push` | O(1) | O(1) |
| `pop` | O(1) | O(1) |
| `top` | O(1) | O(1) |
| `getMin` | O(1) | O(1) |

## 五、学习总结

1. **辅助栈设计思想**：用额外空间换取时间效率
2. **双栈同步维护**：主栈存元素，辅助栈存对应状态
3. **O(1) 获取最小值**：`min_stack[-1]` 始终是当前最小值
4. **两种实现方案**：双栈法 vs 单栈元组法，空间复杂度相同

**问题2**：假设依次执行 `push(-2)`, `push(0)`, `push(-3)`, `getMin()`, `pop()`, `getMin()`，`stack` 和 `min_stack` 各自的状态？

**回答**：
- `push(-2)`: stack=[-2], min_stack=[-2]
- `push(0)`: stack=[-2,0], min_stack=[-2,-2]
- `push(-3)`: stack=[-2,0,-3], min_stack=[-2,-2,-3]
- `getMin()` 输出 -3
- `pop()`: stack=[-2,0], min_stack=[-2,-2]
- `getMin()` 输出 -2

**判断**：✅ 正确，手动模拟完全准确

---

**问题3**：如果 `min_stack` 只在遇到更小值时才压入（非同步压入），会有什么问题？请举例说明。

**回答（补充后）**：重复最小值会导致后续最小值没有压入 min_stack。例如栈为 [5,3,3]，非同步压入的 min_stack 是 [5,3]，弹出第一个3后 getMin() 会返回5，正确答案应该是3。

**判断**：✅ 正确（补充后）

**回答**：空间复杂度没有区别，都是保存2n个元素。双栈法的优点是代码逻辑清晰。
