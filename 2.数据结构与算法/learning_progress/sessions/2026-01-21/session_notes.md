## 复习内容

### Day 11: LeetCode 560 - 和为 K 的子数组

**核心知识点**：
- 前缀和 + 哈希表
- 数学推导：`prefix[j+1] - prefix[i] = K` → `prefix[i] = prefix[j+1] - K`
- 初始化 `{0: 1}` → 处理从索引 0 开始的子数组
- 先查询再更新 → 避免 i=j 的重复计数

**复习题**：`nums = [1, 2, 3, -2, 1]`, `K = 4`

| 步骤 | currentSum | target | result | countMap[target] | 说明 |
|:-----|:----------:|:------:|:------:|:----------------:|:-----|
| 初始 | 0 | - | 0 | - | {0: 1} |
| 1 | 1 | -3 | 0 | 0 | {0:1, 1:1} |
| 2 | 2 | -1 | 0 | 0 | {0:1, 1:1, 3:1} |
| 3 | 3 | 2 | 0 | 0 | {0:1, 1:1, 3:1, 6:1} |
| 4 | 4 | 0 | 1 | 1 | {0:1, 1:1, 3:1, 6:1, 4:1} |
| 5 | 5 | 1 | 2 | 1 | {0:1, 1:2, 3:1, 6:1, 4:1, 5:1} |

**结果**：2 个子数组 `[1, 2, 3, -2]` 和 `[2, 3, -2, 1]`
**状态**：✓ 掌握

### Day 12: LeetCode 128 - 最长连续序列

**核心知识点**：
- HashSet + 从起点扩展
- 通过 `num - 1 not in set` 判断起点
- 从起点向右扩展，记录最长长度
- 时间复杂度 O(n)：每个元素最多访问 2 次

**复习题**：`nums = [0, 3, 2, 5, 4, 1, 8, 7]`

**起点判断**：
- 0：-1 不在 set → 起点 ✓
- 7：6 不在 set → 起点 ✓
- 其他：前一个数都在 set → 不是起点

**扩展结果**：
- 从 0 扩展：0 → 1 → 2 → 3 → 4 → 5 → 6(不存在) → 长度 6
- 从 7 扩展：7 → 8 → 9(不存在) → 长度 2

**结果**：最长连续序列 `[0, 1, 2, 3, 4, 5]`，长度 6
**状态**：✓ 掌握
