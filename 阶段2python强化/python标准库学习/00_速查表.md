## 1. pathlib - 现代路径操作

### 核心记忆：一切皆对象，用 `/` 拼接

| API | 说明 | 示例 |
|-----|------|------|
| `Path(path)` | 创建路径对象 | `p = Path("data/file.txt")` |
| `p / "sub"` | 路径拼接 | `Path("home") / "user"` |
| `p.name` | 文件名 | `"file.txt"` |
| `p.stem` | 主文件名 | `"file"` |
| `p.suffix` | 扩展名 | `".txt"` |
| `p.parent` | 父目录 | |
| `p.exists()` | 是否存在 | |
| `p.is_file()` | 是否是文件 | |
| `p.is_dir()` | 是否是目录 | |
| `p.iterdir()` | 遍历目录（生成器） | |
| `p.glob("*.py")` | 查找文件 | |
| `p.rglob("*.py")` | 递归查找 | |
| `p.read_text()` | 读文件 | |
| `p.write_text()` | 写文件 | |
| `p.mkdir(parents=True)` | 创建目录 | |
| `p.unlink()` | 删除文件 | |

```python
from pathlib import Path
p = Path("data") / "file.txt"
p.write_text("hello")
content = p.read_text()
for f in Path(".").glob("*.py"): print(f)
```

## 2. os - 操作系统接口

### 核心记忆：environ 环境变量，makedirs 创建目录

| API | 说明 |
|-----|------|
| `os.environ` | 环境变量字典 |
| `os.getenv(key)` | 获取环境变量 |
| `os.getcwd()` | 当前工作目录 |
| `os.listdir(path)` | 列出目录内容（返回列表） |
| `os.makedirs(path, exist_ok=True)` | 递归创建目录 |
| `os.remove(path)` | 删除文件 |
| `os.rename(src, dst)` | 重命名 |
| `os.stat(path)` | 文件属性 |
| `os.path.join(p1, p2)` | 拼接路径 |
| `os.path.exists(path)` | 是否存在 |
| `os.path.isfile(path)` | 是否是文件 |
| `os.path.isdir(path)` | 是否是目录 |
| `os.path.splitext(path)` | 分离扩展名 |
| `os.walk(path)` | 遍历目录树 |

```python
import os
os.makedirs("data/sub", exist_ok=True)
for root, dirs, files in os.walk("."): print(files)
```

## 3. json - 数据序列化

### 核心记忆：s=字符串，无s=文件

| API | 说明 | 示例 |
|-----|------|------|
| `json.dumps(obj)` | Python → JSON字符串 | `s = json.dumps({"a": 1})` |
| `json.loads(s)` | JSON字符串 → Python | `obj = json.loads(s)` |
| `json.dump(obj, f)` | 写入文件 | `json.dump(data, f)` |
| `json.load(f)` | 读取文件 | `data = json.load(f)` |

**常用参数：**
- `ensure_ascii=False` - 中文正常显示
- `indent=4` - 美化输出

```python
import json
data = {"name": "张三", "age": 25}
json.dump(data, open("data.json", "w"), ensure_ascii=False, indent=2)
obj = json.load(open("data.json"))
```

## 4. csv - 表格数据处理

### 核心记忆：优先用 Dict 版本

| API | 说明 |
|-----|------|
| `csv.reader(f)` | 读取为列表 |
| `csv.writer(f)` | 写入列表 |
| `csv.DictReader(f)` | 读取为字典（推荐） |
| `csv.DictWriter(f, fieldnames)` | 写入字典（推荐） |
| `writer.writeheader()` | 写入表头 |
| `writer.writerow(row)` | 写入单行 |
| `writer.writerows(rows)` | 写入多行 |

**注意事项：** `open()` 时加 `newline=''`

```python
import csv
with open("file.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["列名"])
```

## 5. random - 随机数生成

### 核心记忆：密码学用 secrets，别用 random

| 分类 | API | 说明 |
|------|-----|------|
| **整数** | `randint(a, b)` | [a, b] 随机整数 |
| | `randrange(start, stop, step)` | 范围内随机 |
| **序列** | `choice(seq)` | 随机选1个 |
| | `choices(seq, k=n)` | 有放回选n个 |
| | `sample(seq, k=n)` | 无放回选n个 |
| | `shuffle(list)` | 原地打乱 |
| **浮点** | `random()` | [0.0, 1.0) |
| | `uniform(a, b)` | [a, b] 随机小数 |
| **科学** | `gauss(mu, sigma)` | 正态分布 |
| **种子** | `seed(n)` | 固定随机序列 |

```python
import random
random.seed(42)
num = random.randint(1, 100)
item = random.choice(["a", "b", "c"])
random.shuffle([1, 2, 3])
```

## 6. re - 正则表达式

### 核心记忆：用 r"" 原始字符串，预编译用 compile

| API | 说明 |
|-----|------|
| `re.search(pattern, s)` | 扫描整个字符串，返回首个匹配 |
| `re.match(pattern, s)` | 只从开头匹配 |
| `re.findall(pattern, s)` | 返回所有匹配（列表） |
| `re.finditer(pattern, s)` | 返回所有匹配（迭代器） |
| `re.sub(pattern, repl, s)` | 替换 |
| `re.split(pattern, s)` | 分割 |
| `re.compile(pattern)` | 预编译（循环时用） |

**常用符号：**

| 符号 | 含义 |
|------|------|
| `.` | 任意字符 |
| `\d` | 数字 |
| `\w` | 字母数字下划线 |
| `\s` | 空白字符 |
| `*` | 0次或多次 |
| `+` | 1次或多次 |
| `?` | 0次或1次 |
| `^` | 开头 |
| `$` | 结尾 |
| `[]` | 字符集 |
| `()` | 分组 |

```python
import re
email_pattern = re.compile(r"[\w\.-]+@[\w\.-]+")
nums = re.findall(r"\d+", "a12b34")  # ['12', '34']
clean = re.sub(r"\d", "*", "a1b2")    # "a*b*"
```

## 7. string - 字符常量

### 核心记忆：字符集 + Template 模板

| 常量 | 内容 |
|------|------|
| `ascii_letters` | a-z + A-Z |
| `ascii_lowercase` | a-z |
| `ascii_uppercase` | A-Z |
| `digits` | 0-9 |
| `hexdigits` | 0-9 + a-f + A-F |
| `punctuation` | 所有标点符号 |

| 类 | 说明 |
|-----|------|
| `Template(tmpl)` | 安全的字符串模板 |
| `.substitute(**kwargs)` | 替换（缺省报错） |
| `.safe_substitute(**kwargs)` | 替换（缺省保留占位符） |

```python
import string
from string import Template

chars = string.ascii_letters + string.digits
t = Template("你好, $name!")
result = t.safe_substitute(name="张三")
```
