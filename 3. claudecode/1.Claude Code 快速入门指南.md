 # Claude Code 快速入门指南

本指南将帮助您在几分钟内掌握AI驱动的编码辅助工具。完成本指南后，您将了解如何使用Claude Code完成常见开发任务。



## 步骤1：安装Claude Code

您可以通过以下任一方式安装Claude Code：

### 安装命令速查

| 安装方式                 | 适用平台               | 命令                                                         |
| ------------------------ | ---------------------- | ------------------------------------------------------------ |
| **原生安装**<br>（推荐） | **macOS/Linux/WSL**    | `curl -fsSL https://claude.ai/install.sh \| bash`            |
|                          | **Windows PowerShell** | `irm https://claude.ai/install.ps1 \| iex`                   |
|                          | **Windows CMD**        | `curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd` |
| **Homebrew**             | macOS                  | `brew install --cask claude-code`                            |
| **WinGet**               | Windows                | `winget install Anthropic.ClaudeCode`                        |

⚠️ **注意**：原生安装方式会自动处理更新，推荐使用。

---

## 步骤2：登录账户

Claude Code需要账户才能使用。首次运行交互式会话时，系统会提示您登录：

```bash
claude
# 首次使用时将提示登录
```

您也可以使用登录命令：

```bash
/login
# 按照提示使用您的账户登录
```

登录后，您的凭据将被保存，无需再次登录。

---

## 步骤3：启动您的第一个会话

在任意项目目录中打开终端并启动Claude Code：

```bash
cd /path/to/your/project
claude
```

您将看到Claude Code的欢迎界面，其中包含会话信息、最近对话和最新更新。

💡 **提示**：输入 `/help` 查看可用命令，或使用 `/resume` 继续之前的对话。

---

## 步骤4：提出第一个问题

让我们从了解您的代码库开始。尝试以下任一命令：

```bash
> what does this project do?
```

Claude将分析您的文件并提供摘要。您也可以提出更具体的问题：

```bash
> what technologies does this project use?

> where is the main entry point?

> explain the folder structure
```

您还可以询问Claude自身的能力：

```bash
> what can Claude Code do?

> how do I use slash commands in Claude Code?

> can Claude Code work with Docker?
```

---

## 步骤5：进行第一次代码修改

现在让Claude Code执行实际的编码任务。尝试一个简单的任务：

```bash
> add a hello world function to the main file
```

Claude Code将：

1. 定位合适的文件
2. 显示建议的更改
3. 请求您的批准
4. 执行编辑

---

## 步骤6：使用Git与Claude Code

Claude Code让Git操作变得对话化：

```bash
> what files have I changed?

> commit my changes with a descriptive message
```

您也可以执行更复杂的Git操作：

```bash
> create a new branch called feature/quickstart

> show me the last 5 commits

> help me resolve merge conflicts
```

---

## 步骤7：修复错误或添加功能

Claude擅长调试和功能实现。用自然语言描述您的需求：

```bash
> add input validation to the user registration form
```

或修复现有问题：

```bash
> there's a bug where users can submit empty forms - fix it
```

Claude Code将：

- 定位相关代码
- 理解上下文
- 实施解决方案
- 运行测试（如可用）

## 常用命令速查表

以下是日常使用的重要命令：

| 命令                    | 功能说明               | 使用示例                            |
| ----------------------- | ---------------------- | ----------------------------------- |
| **`claude`**            | 启动交互式模式         | `claude`                            |
| **`claude "任务描述"`** | 执行一次性任务         | `claude "fix the build error"`      |
| **`claude -p "查询"`**  | 执行单次查询后退出     | `claude -p "explain this function"` |
| **`claude -c`**         | 在当前目录继续最近对话 | `claude -c`                         |
| **`claude -r`**         | 恢复之前的对话         | `claude -r`                         |
| **`claude commit`**     | 创建Git提交            | `claude commit`                     |
| **`/clear`**            | 清除对话历史           | `> /clear`                          |
| **`/help`**             | 显示可用命令           | `> /help`                           |
| **`exit`** 或 `Ctrl+C`  | 退出Claude Code        | `> exit`                            |

查看 [CLI参考文档](https://code.claude.com/docs/en/cli-reference) 获取完整命令列表。
