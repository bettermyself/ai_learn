### Claude Code Hooks

**Hooks** 是 Claude Code 的“自动化拦截器”。它们是用户定义的 Shell 命令或脚本，在 Claude 操作的特定生命周期自动执行。

---

#### 1. 核心价值

* **确定性控制**：不依赖 AI 的自觉，而是用代码强制执行规则（如：禁止修改 `.env`）。
* **流程自动化**：操作前后自动触发（如：写完代码自动运行 Prettier 格式化）。
* **环境集成**：与系统通知、日志审计、CI/CD 深度挂钩。

#### 2. 关键触发点

| 事件名称              | 触发时机                        | 控制能力           |
| --------------------- | ------------------------------- | ------------------ |
| **PreToolUse**        | 工具调用前                      | ⛔ 可阻止工具执行   |
| **PermissionRequest** | 显示权限对话框时                | ✅ 可自动允许或拒绝 |
| **PostToolUse**       | 工具调用完成后                  | 📝 可获取执行结果   |
| **UserPromptSubmit**  | 用户提交提示时（Claude 处理前） | 🔄 可修改或拦截输入 |
| **Notification**      | Claude Code 发送通知时          | 🔔 可自定义通知方式 |
| **Stop**              | Claude 完成响应时               | 📊 可执行清理或统计 |
| **SubagentStop**      | 子代理任务完成时                | 🔗 可处理子任务结果 |
| **PreCompact**        | Claude 即将运行压缩操作前       | 💾 可保存重要上下文 |
| **SessionStart**      | 新会话启动或恢复现有会话时      | 🚀 可初始化环境     |
| **SessionEnd**        | 会话结束时                      | 🧹 可执行清理操作   |

#### 3. 运行机制

1. **输入**：Claude 将操作上下文（工具名、参数如 `file_path`）以 **JSON** 形式传给 Hook 的 `stdin`。
2. **执行**：运行你指定的命令（如 Python 脚本或 Bash 命令）。
3. **输出/控制**：
* **退出码 0**：正常通过。
* **退出码 非0**：拦截操作，阻止执行。



#### 4. 配置方式

通过终端输入 `/hooks` 命令，进入交互式菜单即可添加、修改或删除。
