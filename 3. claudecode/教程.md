 # Claude Code 使用指南

本文档系统介绍 Claude Code 的核心功能与进阶技巧，帮助您高效掌握这一强大工具。

## 基础操作

### 升级 Claude Code

```python
claude update
```

### 记忆管理

- 使用 `#` 符号添加用户记忆或项目记忆，持久化存储重要信息

### 状态监控
- 密切关注输出状态指示器（小绿点、小白点）
- 及时响应工具调用和授权请求

### 模式切换
**快捷键**：`Shift + Tab`  

在以下三种模式间循环切换：

- 普通模式
- 编辑模式
- Plan 模式

### 思考深度控制

通过在提示词末尾添加特定指令，控制 AI 的思考深度：

| 指令           | 思考深度     |
| -------------- | ------------ |
| `think`        | 基础思考     |
| `think hard`   | 深度思考     |
| `think harder` | 更深思考     |
| `ultra think`  | 最高级别思考 |

### 快捷键操作

| 操作       | 快捷键               | 说明                                     |
| ---------- | -------------------- | ---------------------------------------- |
| 清空输入框 | 双击 `ESC`           | 快速清除当前输入内容                     |
| 回滚对话   | 空输入框下双击 `ESC` | ⚠️ 仅回滚对话记录，**不撤销**已完成的操作 |

### 版本控制建议
💡 **强烈推荐**：使用 Git 管理项目版本，确保工作安全可靠

## 进阶技巧

### YOLO（狂飙）模式
⚠️ **警告：高风险模式，仅限特定场景使用**

| 特性           | 详细说明                                                  |
| -------------- | --------------------------------------------------------- |
| **启用命令**   | `claude --dangerously-skip-permissions`                   |
| **视觉提示**   | 右下角显示 *Bypassing Permissions* 标识                   |
| **自动行为**   | 无需人工授权即可下载依赖、创建文件、运行脚本              |
| **⚠️ 安全风险** | AI 获得完全文件读写权限，可能导致重要文件被误删或意外修改 |

### 图片插入
支持四种便捷方式：

1. **路径粘贴**：复制图片路径 → `Command + V`
2. **文件粘贴**：复制图片文件 → `Command + V`
3. **截图粘贴**：截图后 → `Control + V`
4. **拖拽上传**：直接拖拽图片文件到对话框

💡 Claude 可识别图片内容并基于视觉信息回答问题

### 文件引用
提供多种文件引用方式，灵活满足不同场景需求：

- **拖拽上传**：直接拖拽文件到对话框
- **当前目录引用**：输入 `@` 选择当前目录下的文件
- **全局搜索**：输入 `@/` + 文件名进行项目全局搜索
- **关键词触发**：输入关键词后按 `Tab` 触发全局搜索
- **自动上下文**：编辑器中当前打开的文件自动加入上下文
- **精确选区**：选中代码行后，Claude 仅解析选区内容

### MCP 插件管理
MCP（Model Context Protocol）插件可扩展 Claude 的功能边界。

**常用命令**：

| 命令                                         | 说明                                            |
| -------------------------------------------- | ----------------------------------------------- |
| `/mcp`                                       | 查看当前项目的插件列表                          |
| `claude mcp add -s user <plugin_name> <url>` | 全局安装 MCP 插件（`-s user` 参数表示全局安装） |
| `claude mcp list`                            | 验证已安装的 MCP 插件                           |

💡 全局安装后，可在任何项目内通过 `/mcp` 命令访问和使用该插件

### 模型手动切换
通过输入 `/model` 命令打开模型选择界面：

| 模式            | 行为特征                                  | 适用场景         |
| --------------- | ----------------------------------------- | ---------------- |
| **默认模式**    | 优先使用 Opus，超过 50% 自动切换至 Sonnet | 平衡成本与性能   |
| **Opus 模式**   | 始终使用 Opus 模型                        | 追求最高质量输出 |
| **Sonnet 模式** | 始终使用 Sonnet 模型                      | 注重成本效益     |

💡 根据任务的复杂度、成本预算和性能需求灵活选择
