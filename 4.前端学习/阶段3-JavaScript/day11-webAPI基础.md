## 一、正则表达式概述

### 1.1 什么是正则表达式

**正则表达式**（Regular Expression）是一种用于字符串匹配的模式规则。

### 1.2 使用场景

| 场景         | 说明                         | 示例                   |
| :----------- | :--------------------------- | :--------------------- |
| **表单验证** | 验证用户输入格式是否符合要求 | 手机号验证（11位数字） |
| **内容过滤** | 替换敏感词或特定内容         | 过滤不当言论           |
| **数据提取** | 从字符串中获取特定部分       | 提取邮箱、电话号码     |



## 二、正则表达式基础

### 2.1 基本使用

正则表达式使用两个步骤：**定义规则** → **使用规则**

```javascript
// 1. 定义规则（使用 / / 字面量）
const reg = /web/

// 2. 使用正则 - test() 方法
// 功能：检查字符串是否匹配正则规则
// 返回值：匹配返回 true，不匹配返回 false

const str = 'web前端开发'
console.log(reg.test(str))        // true
console.log(reg.test('java开发'))  // false
```

### 2.2 元字符分类

| 类型         | 说明                               | 示例                       |
| :----------- | :--------------------------------- | :------------------------- |
| **普通字符** | 仅匹配自身，如字母、数字           | `/abc/` 只匹配 "abc"       |
| **元字符**   | 具有特殊含义的字符，提高匹配灵活性 | `/[a-z]/` 匹配所有小写字母 |



## 三、核心元字符详解

### 3.1 边界符（位置符）

边界符用于指定字符所处的位置。

| 符号    | 名称     | 含义               | 示例                     |
| :------ | :------- | :----------------- | :----------------------- |
| `^`     | 开头符   | 匹配字符串的开头   | `/^web/` 匹配以"web"开头 |
| `$`     | 结束符   | 匹配字符串的结尾   | `/web$/` 匹配以"web"结尾 |
| `^...$` | 精确匹配 | 字符串必须完全匹配 | `/^web$/` 只匹配"web"    |

```javascript
// 1. 匹配开头 ^
const reg1 = /^web/
reg1.test('web前端')    // true
reg1.test('前端web')    // false

// 2. 匹配结尾 $
const reg2 = /web$/
reg2.test('前端web')    // true
reg2.test('web前端')    // false

// 3. 精确匹配 ^...$
const reg3 = /^web$/
reg3.test('web')        // true
reg3.test('webweb')     // false
reg3.test('前端web')    // false
```

### 3.2 量词

量词用于设定某个模式的重复次数。

| 符号    | 含义       | 重复次数      | 示例                                  |
| :------ | :--------- | :------------ | :------------------------------------ |
| `*`     | 零次或多次 | `>= 0`        | `/^w*$/` 匹配 "", "w", "ww"           |
| `+`     | 一次或多次 | `>= 1`        | `/^w+$/` 匹配 "w", "ww"，不匹配 ""    |
| `?`     | 零次或一次 | `0 或 1`      | `/^w?$/` 匹配 "", "w"，不匹配 "ww"    |
| `{n}`   | 固定 n 次  | `= n`         | `/^w{3}$/` 只匹配 "www"               |
| `{n,}`  | 至少 n 次  | `>= n`        | `/^w{2,}$/` 匹配 "ww", "www"...       |
| `{n,m}` | n 到 m 次  | `n <= x <= m` | `/^w{2,4}$/` 匹配 "ww", "www", "wwww" |

```javascript
// 量词使用示例
const reg1 = /^w*$/      // 零次或多次
const reg2 = /^w+$/      // 一次或多次
const reg3 = /^w?$/      // 零次或一次
const reg4 = /^w{3}$/    // 恰好3次
const reg5 = /^w{2,}$/   // 至少2次
const reg6 = /^w{2,4}$/  // 2到4次
```

> ⚠️ **注意**：使用 `{n,m}` 时，逗号两侧**千万不要加空格**，否则会导致匹配失败。

### 3.3 范围符

范围符用于限定匹配字符的范围（限一个字符）。

| 符号     | 含义                         | 示例                             |
| :------- | :--------------------------- | :------------------------------- |
| `[abc]`  | 字符集合，匹配包含的任一字符 | `/^[abc]$/` 匹配 "a"、"b" 或 "c" |
| `[a-z]`  | 连字符，匹配范围内的字符     | `/^[a-z]$/` 匹配任意小写字母     |
| `[^a-z]` | 取反符，匹配不在范围内的字符 | `/^[^a-z]$/` 匹配非小写字母      |

```javascript
// 1. [abc] - 多选1
const reg1 = /^[abc]$/
reg1.test('a')   // true
reg1.test('d')   // false

// 2. [a-z] - 连字符范围
const reg2 = /^[a-z]$/
reg2.test('a')   // true
reg2.test('A')   // false

// 组合使用：小写字母、大写字母、数字
const reg3 = /^[a-zA-Z0-9]$/

// 实际应用：用户名验证（6-16位，字母数字下划线）
const reg4 = /^[a-zA-Z0-9_]{6,16}$/
reg4.test('abcd1')    // false（不足6位）
reg4.test('abcd12')   // true
reg4.test('AB_cd12')  // true

// 3. [^a-z] - 取反符
const reg5 = /^[^a-z]$/
reg5.test('a')   // false
reg5.test('A')   // true
reg5.test('8')   // true
```

### 3.4 字符类（预定义元字符）

常见模式的简写方式：

| 符号 | 含义               | 等价于          | 示例                     |
| :--- | :----------------- | :-------------- | :----------------------- |
| `\d` | 数字               | `[0-9]`         | `/^\d+$/` 匹配数字字符串 |
| `\D` | 非数字             | `[^0-9]`        | `/^\D+$/` 匹配非数字     |
| `\w` | 单词字符           | `[a-zA-Z0-9_]`  | `/^\w+$/` 匹配单词       |
| `\W` | 非单词字符         | `[^\w]`         | `/^\W+$/` 匹配特殊符号   |
| `\s` | 空白字符           | `[ \t\n\r\f\v]` | `/^\s*$/` 匹配空白       |
| `\S` | 非空白字符         | `[^\s]`         | `/^\S+$/` 匹配非空白     |
| `.`  | 除换行外的任意字符 | -               | `/^.$/` 匹配任意单个字符 |



## 四、替换与修饰符

### 4.1 replace() 方法

`replace()` 方法用于替换字符串中的匹配内容。

```javascript
const str = '欢迎大家学习前端，相信大家一定能学好前端，都成为前端大神'

// 1. 不带修饰符 - 只替换第一个匹配项
const str1 = str.replace(/前端/, 'web')
// 结果："欢迎大家学习web，相信大家一定能学好前端，都成为前端大神"

// 2. 带 g 修饰符 - 替换所有匹配项
const str2 = str.replace(/前端/g, 'web')
// 结果："欢迎大家学习web，相信大家一定能学好web，都成为web大神"
```

### 4.2 常用修饰符

| 修饰符 | 含义                 | 说明                                 |
| :----- | :------------------- | :----------------------------------- |
| `g`    | global（全局）       | 匹配所有满足条件的结果，不只是第一个 |
| `i`    | ignore（忽略大小写） | 匹配时不区分大小写                   |
| `m`    | multiline（多行）    | 允许多行匹配                         |

```javascript
// i 修饰符：不区分大小写
const str = 'Hello World'
str.replace(/hello/i, 'Hi')  // "Hi World"

// gi 组合：全局且不区分大小写
str.replace(/o/gi, '0')      // "Hell0 W0rld"
```



## 五、相关 DOM 操作

### 5.1 change 事件

给 `input` 元素注册 `change` 事件，当**值被修改且失去焦点**后触发。

```javascript
const input = document.querySelector('input')

input.addEventListener('change', function() {
  console.log('值已改变：', this.value)
})
```

### 5.2 classList.contains() 方法

用于判断元素是否包含某个 CSS 类。

```javascript
const element = document.querySelector('.box')

// 检查是否包含 'active' 类
if (element.classList.contains('active')) {
  console.log('包含 active 类')
} else {
  console.log('不包含 active 类')
}
```
