## 1. 知识点摘要
- **var 变量提升**：声明被提升到作用域顶部，赋值留在原地 → 输出 `undefined`
- **let/const 暂时性死区（TDZ）**：声明前使用直接报 `ReferenceError`
- **块级作用域**：`let`/`const` 在 `{}` 内有效，`var` 只有函数作用域
- **作用域链**：从内到外逐层查找变量（类似 Python LEGB）
- **var 循环陷阱**：`for (var i...)` + `setTimeout` 输出 `3,3,3`，用 `let` 修复
