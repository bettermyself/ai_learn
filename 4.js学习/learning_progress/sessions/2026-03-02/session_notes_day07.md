## 1. 知识点摘要
- **JS 七种原始类型**：String, Number, BigInt, Boolean, Symbol, Undefined, Null
- **null vs undefined**：`undefined` 是引擎给的（未赋值），`null` 是开发者给的（主动清空）
- **`==` vs `===`**：`==` 触发类型转换，`===` 严格比较（永远用 `===`）
- **隐式类型转换陷阱**：`[] == ![]` → true, `{} + []` → 0, `[] + []` → ""
- **空值合并运算符 `??`**：只判断 null/undefined，不判断其他 falsy 值
- **可选链 `?.`**：安全访问深层属性，遇到 null/undefined 返回 undefined 而不报错
