## 1 迁移学习的概念

### 1.1 预训练模型(Pretrained model)

```properties
定义: 简单来说别人训练好的模型。一般预训练模型具备复杂的网络模型结构；一般是在大量的语料下训练完成的
```



**预训练语言模型的类别**

```properties
现在我们接触到的预训练语言模型，基本上都是基于transformer这个模型迭代而来的
因此划分模型类别的时候，以transformer架构来划分：
Encoder-Only: 只有编码器部分的模型，代表：BERT
Decoder-Only: 只要解码器部分的模型，代表：GPT
Encoder-Decoder: 本质就是transformer架构，代表：T5
```



### 1.2 微调(Fine-tuning)

✅ 定义：

在预训练模型的基础上：

- **修改部分参数** 或 **新增输出结构**
- 在 **小规模标注数据** 上进行训练
- 使模型更好地适应 **特定任务**

✅ 优势：

- 节省训练成本（无需从头训练）
- 数据需求小（几百~几千条标注即可）
- 效果优于从零训练



### 1.3 迁移学习的两种方式

| 方式         | 是否训练 | 数据需求     | 适用场景           | 示例                  |
| ------------ | -------- | ------------ | ------------------ | --------------------- |
| **直接使用** | ❌        | 无           | 通用任务、开箱即用 | FastText 预训练词向量 |
| **微调适配** | ✅        | 少量标注数据 | 特定任务适配       | BERT 微调做文本分类   |

> 微调：进行垂直领域数据的微调，一般在预训练网络模型后，加入自定义网络，自定义网络模型的参数需要训练，但是预训练模型的参数可以全部微调或者部分微调或者不微调。

### 3.2 特征抽取

```properties
定义:将文本输入模型，得到特征向量的表示。仅对输入文本进行编码，提取其语义特征，不执行具体下游任务（如分类、生成等）。提取的特征通常需要与其他模型或算法结合使用，属于预训练模型的应用范畴。
```

代码实现

```python
# 2.实现特征提取任务

# 导入必要的库
from transformers import pipeline
import torch

# 定义特征提取函数
def dm02_text_feature():
    """
    使用预训练的中文 BERT 模型对输入文本进行特征提取。
    输出每个 token 的向量表示（通常为 768 维）。
    """

    # 使用 pipeline 加载本地中文预训练模型（bert-base-chinese）
    # task="feature-extraction" 表示执行特征提取任务
    model = pipeline(
        task="feature-extraction",
        model="./model/bert-base-chinese"
    )

    # 输入中文文本，模型将自动添加 [CLS] 和 [SEP] 特殊标记
    input_text = "人生该如何起头"

    # 提取文本的语义特征（返回的是一个嵌套列表）
    result = model(input_text)

    # 将结果转换为 PyTorch 张量，并打印其维度
    # 典型输出维度为：(1, 序列长度, 768)
    print(f"result --> {torch.tensor(result).size()}")

# 如果作为主程序运行，则执行函数

    dm02_text_feature()

    # 假设 MASK 位于第 6 个 token

> ✅**Tokenizer 方法比较：`encode` 与 `encode_plus`**
>
> | 特性       | `encode`                 | `encode_plus`                                 |
> | :--------- | :----------------------- | :-------------------------------------------- |
> | 返回值类型 | list（仅包含 token IDs） | dict（包含 `input_ids`、`attention_mask` 等） |
> | 功能丰富度 | 基础功能                 | 丰富功能                                      |
> | 适用场景   | 简单文本编码             | 复杂 NLP 任务（如分类、问答、NER 等）         |
> | 额外信息   | 无                       | 提供 `attention_mask`、`token_type_ids` 等    |
>
> 说明：
>
> - **`encode`** 方法适用于快速获取 token ID 列表，适用于简单的文本编码需求。
> - **`encode_plus`** 方法返回一个字典，包含更多模型所需的信息（如注意力掩码、token 类型 ID 等），适用于复杂的 NLP 任务。
>
> ---

> ✅**`my_model.eval()` 和 `torch.no_grad()` 的区别**
>
> `my_model.eval()` 和 `torch.no_grad()` 是两个**完全不同维度**的设定，**缺一不可**，也不能互相替代。
>
> | 维度         | `model.eval()`                               | `torch.no_grad()`                    |
> | :----------- | :------------------------------------------- | :----------------------------------- |
> | **作用对象** | 模型 **本身**                                | **PyTorch 的自动求导引擎**           |
> | **控制内容** | 改变 **网络层行为**（Dropout、BatchNorm 等） | 关闭 **梯度计算**（节省显存、加速）  |
> | **是否互斥** | 否，**必须同时用**                           | 否，**推荐一起用**                   |
> | **典型场景** | 推理、验证                                   | 推理、验证、任何不需要反向传播的地方 |
> | **代码示例** | `model.eval()`                               | `with torch.no_grad(): ...`          |
>
> **1. `model.eval()` —— 告诉模型“我现在要测试”**
>
> - **只影响网络里带“训练/测试”双模式的层**：
>   - `Dropout` → 停止随机丢弃，保留全部权重
>   - `BatchNorm` → 用**滑动平均**的均值/方差，不再用当前 batch 统计量
> - **不会**关闭梯度，**不会**节省显存，**不会**加速计算
> - **必须手动调用**，否则模型仍处在 `train()` 模式，推理结果会**带随机性**且**BatchNorm 统计量错误**
>
> **2. `torch.no_grad()` —— 告诉 PyTorch“别给我算梯度”**
>
> - **上下文管理器**，进入该作用域后：
>   - **不构造计算图**，`requires_grad=True` 的张量也不会累积梯度
>   - **显存占用直接减半**（省去了保存中间激活值用于反向传播）
>   - **速度更快**（省去了图构建与梯度缓冲区维护）
> - **对模型行为毫无影响**，Dropout/BatchNorm 该咋样还咋样
>
> **3. 正确姿势：推理/验证时同时用**
>
> ```python
> my_model.eval()          # 1. 网络层行为切换
> with torch.no_grad():    # 2. 关闭梯度
>     outputs = my_model(inputs)
> ```
>
> **4. 常见误区**
>
> | 错误用法                                     | 后果                                                         |
> | :------------------------------------------- | :----------------------------------------------------------- |
> | 只用 `model.eval()`，不用 `no_grad()`        | 结果正确，但**浪费显存、速度变慢**                           |
> | 只用 `no_grad()`，忘记 `model.eval()`        | **Dropout 仍在随机丢弃，BatchNorm 用当前 batch 统计量**，推理结果**不稳定/错误** |
> | 把 `no_grad()` 写成装饰器/函数外层的全局开关 | 可以，但**别忘了** `model.eval()`                            |
>
> 一句话总结
> `model.eval()` 是**模型行为切换**，`torch.no_grad()` 是**梯度引擎开关**；推理时**两个都要**，**不能互相替代**。

def dm04_test_qa():
    """
    使用中文预训练 MRC（阅读理解）模型进行问答演示。
    针对同一段上下文，循环回答多个问题。
    """
    # 1. 加载分词器
    my_tokenizer = AutoTokenizer.from_pretrained("./model/chinese_pretrain_mrc_roberta_wwm_ext_large")

    # 2. 加载问答模型
    my_model = AutoModelForQuestionAnswering.from_pretrained("./model/chinese_pretrain_mrc_roberta_wwm_ext_large")

    # 3. 准备样本：上下文与问题列表
    context = '我张三 我是一个程序员 我的喜好是打篮球'
    questions = [
        "我是谁？",
        "我是做什么的？",
        "我的爱好是什么？"
    ]

    # 4. 将模型设为评估模式（关闭 Dropout 等训练相关层）
    my_model.eval()

    # 遍历每个问题，进行问答推理
    for question in questions:
        print(f'question --> {question}')

        # 4.1 对问题+上下文进行编码，返回 PyTorch 张量
        inputs = my_tokenizer.encode_plus(question, context, return_tensors='pt')
        print(f'inputs --> {inputs}')

        # 4.2 将编码结果输入模型，获取输出
        outputs = my_model(**inputs)

        # 5. 从模型输出中提取答案的起止位置（最大 logits 对应的索引）
        start_index = torch.argmax(outputs.start_logits, dim=-1).item()
        end_index = torch.argmax(outputs.end_logits, dim=-1).item()

        # 6. 根据起止索引，从 input_ids 中切片出答案对应的 token ID
        a = inputs["input_ids"][0][start_index: end_index + 1]

        # 7. 将 token ID 转换为真实 token（中文子词）
        results = my_tokenizer.convert_ids_to_tokens(a)
        print(f'results --> {results}')
```

def dm06_test_ner():
    """
    对单条中文文本进行命名实体识别（NER）预测并打印结果
    """
    
    # 1.加载分词器
    my_tokenizer = AutoTokenizer.from_pretrained("./model/roberta-base-finetuned-cluener2020-chinese")
    
    # 2.加载模型
    my_model = AutoModelForTokenClassification.from_pretrained("./model/roberta-base-finetuned-cluener2020-chinese")
   
    # 3. 加载配置文件（含 id2label 映射）

    # 4.准备样本
    text = "我爱北京天安门，天安门上太阳升"
    
    # 5. 将文本转为模型输入
    inputs = tokenizer.encode_plus(
        text,
        return_tensors="pt",  # 返回 PyTorch 张量
    )

    # 6. 推理模式
    my_model.eval()
    
    # 7. 前向传播得到 logits
    with torch.no_grad():
    	outputs = my_model(**inputs).logits  # shape: [batch_size, seq_len, num_labels]

    # 8. 将 input_ids 还原为 token 字符串
    tokens = my_tokenizer.convert_ids_to_tokens(inputs["input_ids"][0])
	
    # 9. 获取特殊 token 列表，用于过滤
    special_tokens = tokenizer.all_special_tokens  # 例如 ['[PAD]', '[CLS]', '[SEP]', '[UNK]', '[MASK]']
    
    # 10. 逐 token 解码预测标签
    results = []
    for tok, logit_vec in zip(tokens, logits[0]):
        # 跳过特殊 token
        if tok in special_tokens:
            continue

        # 取概率最大的类别
        pred_id = torch.argmax(logit_vec, dim=-1).item()
        pred_label = config.id2label[pred_id]

        results.append((tok, pred_label))

    # 11. 打印结果
    print("NER 预测结果：")
    for tok, label in results:
        print(f"{tok} -> {label}")
