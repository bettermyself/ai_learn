## 1 迁移学习的概念

### 1.1 预训练模型(Pretrained model)

```properties
定义: 简单来说别人训练好的模型。一般预训练模型具备复杂的网络模型结构；一般是在大量的语料下训练完成的
```



**预训练语言模型的类别**

```properties
现在我们接触到的预训练语言模型，基本上都是基于transformer这个模型迭代而来的
因此划分模型类别的时候，以transformer架构来划分：
Encoder-Only: 只有编码器部分的模型，代表：BERT
Decoder-Only: 只要解码器部分的模型，代表：GPT
Encoder-Decoder: 本质就是transformer架构，代表：T5
```



### 1.2 微调(Fine-tuning)

✅ 定义：

在预训练模型的基础上：

- **修改部分参数** 或 **新增输出结构**
- 在 **小规模标注数据** 上进行训练
- 使模型更好地适应 **特定任务**

✅ 优势：

- 节省训练成本（无需从头训练）
- 数据需求小（几百~几千条标注即可）
- 效果优于从零训练



### 1.3 迁移学习的两种方式

| 方式         | 是否训练 | 数据需求     | 适用场景           | 示例                  |
| ------------ | -------- | ------------ | ------------------ | --------------------- |
| **直接使用** | ❌        | 无           | 通用任务、开箱即用 | FastText 预训练词向量 |
| **微调适配** | ✅        | 少量标注数据 | 特定任务适配       | BERT 微调做文本分类   |

> 微调：进行垂直领域数据的微调，一般在预训练网络模型后，加入自定义网络，自定义网络模型的参数需要训练，但是预训练模型的参数可以全部微调或者部分微调或者不微调。

### 3.2 特征抽取

```properties
定义:将文本输入模型，得到特征向量的表示。仅对输入文本进行编码，提取其语义特征，不执行具体下游任务（如分类、生成等）。提取的特征通常需要与其他模型或算法结合使用，属于预训练模型的应用范畴。
```

代码实现

```python

from transformers import pipeline
import torch

# 定义特征提取函数
def dm02_text_feature():
    """

    """

        task="feature-extraction",

    )

    result = model(input_text)

    # 将结果转换为 PyTorch 张量，并打印其维度
    # 典型输出维度为：(1, 序列长度, 768)
    print(f"result --> {torch.tensor(result).size()}")
```

```python
    encoded = tokenizer.encode_plus(
        text,
        return_tensors="pt"   # 返回 pytorch 张量

    model.eval()
    with torch.no_grad():

        print(f"logits.shape -> {logits.shape}")  # 例：[1, 12, 21128]
```
