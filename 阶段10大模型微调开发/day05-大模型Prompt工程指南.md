## 1. 概念

### 什么是提示工程

**提示工程**（Prompt Engineering），也称为上下文提示（In-Context Prompting），是一种**不更新模型权重**的前提下，通过优化输入指令来引导大语言模型（LLM）行为以获得所需结果的方法论。

### 提示词的本质

在AI交互中，**Prompt**指用户向大模型发出的指令集合，例如：

- 「讲个笑话」
- 「用Python编写贪吃蛇游戏」
- 「撰写商业企划书」

💡 **核心认知**：提示工程不仅关乎提示词设计，更涵盖了与LLM交互的全套技能体系，包括安全控制、能力增强（如结合领域知识、外部工具）等。

### 2.1 清晰的指令

⚠️ **核心原则**：任何Prompt技巧都不如**清晰表达需求**。如同人际沟通，明确的表达是有效交互的基础。

#### 2.1.1 详细的描述

**技巧**：提供充足的上下文、细节和约束条件。

**效果对比**：

- ❌ 模糊请求：`帮我写一封情书`
- ✅ 清晰请求：`用一些温柔的话语写一封情书，表达我对你的仰慕和思念，要求不少于500字`

#### 2.1.2 让模型充当某个角色

**技巧**：通过角色设定使模型输出更专业、更具针对性。

**示例**：



复制

```
我需要你充当一个AI算法面试官的角色，要求你自主地对我进行AI面试。
规则：每次只提一个问题，待我回答完成后，再出下一道题。
```

#### 2.1.3 使用分隔符标明输入的不同部分

**技巧**：使用三引号、XML标签、中括号等明确划分文本边界，帮助模型理解结构。

**最佳实践**：

#### 2.1.4 对任务指定步骤

**技巧**：将可拆分的任务流程化，明确执行顺序。

**示例**：

#### 2.1.5 提供例子（Few-Shot Learning）

**技巧**：先展示期望的输入输出格式，让模型模仿学习。

**示例**：

```

```

**技巧**：明确目标输出的长度单位（段落、句子、字数等）。

**注意事项**：

- ✅ **有效**：指定段落数、要点数量

### 2.2 文本参考

**核心价值**：通过提供参考文本，显著降低模型"幻觉"（一本正经地胡说八道）现象。

#### 2.2.1 使用参考文本作答

**方法**：知识库问答的标准范式，强制模型基于给定信息组织答案。

**示例**：



复制

```
根据下文三重引号内的文章回答问题。如果找不到答案，请写"我找不到答案"，禁止编造。

"""<在此插入知识库文档>"""
"""<可插入多个文档片段>"""

问题：<用户具体问题>
```

#### 2.3.2 处理长对话：总结或过滤信息

**挑战**：模型上下文长度有限，无法无限延续对话

**解决方案**：

1. **阈值触发总结**：当对话长度达到阈值时，自动总结历史
2. **持续后台总结**：模型在对话过程中实时维护摘要
3. **向量库存储**：将历史记录向量化，动态查询相关上下文

#### 2.3.3 分段总结长文本并递归构建完整摘要

**适用场景**：处理超长文档（如书籍、论文）

**方法**：

- 先总结每个章节/段落
- 再对章节总结进行二次汇总
- 优势：避免单次处理信息过载

### 2.4 给模型"思考"的时间

**技术原理**：链式思考（Chain-of-Thought, CoT），通过`think step by step`激发逐步推理能力。

#### 2.4.1 引导模型在得出结论前生成自己的答案

**目的**：激活模型的内部推理过程，避免草率判断

**示例**：



复制

```
用户：问题"1+1=3"是否正确？答案"正确，因为在三维空间里1+1是立体的，所以等于3"。
要求：判断前请先独立思考正确答案，再评估给定答案的正确性。
```

**模型响应逻辑**：

1. 先计算标准答案：1+1=2
2. 分析三维概念与加法运算的关系
3. 最终判断：不正确

#### 2.4.2 隐藏推理过程，只展示最终答案

**场景**：需要简洁输出的情况

**示例**：

```
用户：如何用Python反转字符串？要求：仅输出代码，不附加任何解释。
```

Python

```python
# 预期输出（无文字说明）

```

#### 2.4.3 处理答案不完整的问题

**技巧**：通过补充细节和限定条件，引导模型完善回答

**效果对比**：

- **初次提问**：`JavaScript是世界上最好的语言吗？`
  - 回答：泛泛而谈，缺乏针对性
- **优化提问**：`在前端开发中，JavaScript是世界上最好的语言吗？要求：只回答最终结论`
  - 回答：更聚焦、更具参考价值
